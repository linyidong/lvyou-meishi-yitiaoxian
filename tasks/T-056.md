# T-056 技术栈页重做：一页铺开（取消 tab）

> 用户 2026-10-25：「技术栈页面需要重新设计一下，看看能不能一页展示，目前内容比较分散」。

## 1. 目标

把现在 4 个 tab（分层架构/请求链路/关键目录/自检命令）改为**一页铺开**：
- 不需要点击切换 tab 才能看到内容；滚动即可看到全部
- 保留动效（数字递增、连线流动、hover 高亮），但不要求"点击展开才出现"

## 2. 建议布局（桌面 1440）

```
┌─ 顶部：标题 + 一句话定位 ────────────────────────────┐
├─ 统计条：82 单测 · 8 E2E · 32 API · 32 迁移 · 15 表 · 25 页面（6 卡横排）─┤
├─ 架构链路（横向流程 + 外部依赖）───────────────────────┤
│   浏览器 → Next Route Handlers → Supabase(PostgREST/GoTrue) → Postgres
│                     ↘ 高德 / DeepSeek / 腾讯云 OCR（外部服务，虚线连接）
├─ 技术栈 6 卡（3 列 × 2 行，全部可见）──────────────────┤
│   前端 | 服务端 | 数据
│   地图与算路 | AI 与外部服务 | 质量与运维
│   每卡：图标+层名+条目（名称+徽章+一句话），条目 hover 发光
├─ 底部双栏：关键目录 | 自检命令（紧凑列表，全部可见）──────┤
└──────────────────────────────────────────────────┘
```

## 3. 具体要求

- **不要 tab**；用滚动展示全部
- 桌面 1440 下尽量在 **1.5 屏内**看完（紧凑间距、卡片内条目单行 + 悬停显示说明）
- 手机 390：单列堆叠、无横向溢出；卡片可折叠（可选）
- 配色沿用：深石板底 + `primary-from→primary-to` 渐变 + teal 点缀
- 保留：数字递增、SVG 连线动画、hover 发光；`prefers-reduced-motion` 关闭动画
- 数据仍取 `config/messages.ts` 的 `ADMIN_TECH_STACK`（可调整结构，但内容必须真实）

## 4. 不做什么

- 不新增未使用的技术
- 不引图表/动画库
- 不改其它后台页

## 5. 验收标准

- [ ] 页面无 tab；打开即看到：统计、链路、6 层技术栈、关键目录、自检命令
- [ ] 1440 下总高度 ≤ 1.5 屏（约 ≤1400px），无大片空白
- [ ] 390 下无横向溢出，内容可读
- [ ] hover 有高亮/发光；数字进入视口递增
- [ ] 内容与真实栈一致（无 Go/MySQL/Redis/Vue）
- [ ] `typecheck` 0、`test:run` 全过、`test:e2e` 8 条通过
- [ ] 改完重启 dev 再截图（A8）

## 6. 测试方案（Harness）

1. 截图 1440 全页（量 `document.body.scrollHeight`，确认 ≤1.5 屏）
2. 390 截图确认无溢出
3. 检查无 tab 按钮残留

## 7. 失败恢复

`git revert <commit>`

## 8. 风险等级

**低**（纯展示）
