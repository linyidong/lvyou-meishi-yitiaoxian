# T-063 Windows 启动体验优化：自动选对 IP + 自动开浏览器 + 醒目手机地址（补卡）

> 补记于 2026-11-08（T-064）。实施完成并提交 `599979a`（2026-10-25），当时未建任务卡，现补写。

## 1. 用户诉求

Windows 上双击启动后：
1. 黑窗要能**自动判断哪块网卡的 IP 是手机能访问的**（机器上常有 Docker/WSL/VPN 虚拟网卡）；
2. 自动打开电脑浏览器；
3. 把「手机访问地址」**醒目打印**出来（并复制到剪贴板）。

## 2. 实现

### ① `windows/get-ip.ps1`（新增）

选 IP 规则（按序）：
1. 只看 `Status=Up` 的 IPv4，排除 `169.254.*` / `127.*`；
2. 排除虚拟网卡：Docker / vEthernet / WSL / Hyper-V / VMware / VirtualBox / Loopback / Tailscale / ZeroTier / VPN / TAP；
3. 优先选**有默认网关**的网卡；
4. 网段优先级 `192.168.*` > `10.*` > 其它（`172.16-31.*` 次选，Docker 常用）；
5. 按 `InterfaceMetric` 排序；
6. 全部失败退回第一条私网地址。
- `诊断.bat -All` 打印所有候选（IP / 网卡名 / 网关），便于人工确认。

### ② `windows/启动项目.bat`（重写）

- 5 步进度：Node 版本 → 配置文件 → Supabase（自动 `docker compose up -d` + 30s 轮询）→ 依赖/构建（首次 `npm ci` + `next build`，失败降级 dev）→ 启动应用（等端口就绪，最多 90s）。
- 就绪后自动 `start http://localhost:3000`。
- 方框内打印 `手机访问：http://<IP>:3000`，并复制到剪贴板。
- 提示关闭/诊断入口。
