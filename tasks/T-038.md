# T-038 图标收尾：关键词优先级 + 视觉尺寸归一 + 宫殿/展馆区分

> T-037 验收发现的三个小问题。

## 1. 要修的

### ① 关键词优先级错误
`马老三肉丁胡辣汤` 被判定为 `skewer`（烧烤），应为 `bowl`（汤）。
原因：`skewer` 规则含「肉」，先于「汤」命中。

修法（美食侧匹配顺序调整为）：
```
hotpot → skewer(串/烧烤/烤串) → dumpling(饺/包/馄饨/抄手) →
coffee(咖啡/茶) → bowl(面/粉/饭/汤/锅/肉) → 默认
```
即：`skewer` 只匹配「串 / 烧烤 / 烤串 / 烤肉」，不再用单独「肉」；`汤` 归 `bowl`。

### ② 图标视觉尺寸不一致
首页实测图标宽度：22/22/20/20/21/21/18/18/19/19（同一张图里大小不一）。
修法：所有 glyph 统一画在 **24×24 viewBox** 内、`width/height` 显式设为同一值（首页 18、登录页 18、Canvas 18），不依赖各图标自身宽高比。

### ③ palace vs museum 小尺寸区分
12–14px 下两者仍易混。要求：
- palace：三层重檐 + 底部台阶（横向更宽）
- museum：单层三角山墙 + 4 根立柱（竖向线条明显）
- 两者轮廓在 12px 下能靠"层数/立柱"区分（贴 12px 放大对比图）
