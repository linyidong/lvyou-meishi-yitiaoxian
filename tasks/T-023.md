# T-023 移动端第二轮：图标/密度/后台表格改卡片

> 由 Harness 起草。用户 2026-10-22 13:50 反馈「图标偏小、界面拥挤」，并附后台路线列表与路线详情两张真机截图。
> 用户已确认范围：**C 端 + 后台都做**。

## 1. 目标

1. **图标**：关键信息与可点元素的图标从 16px 提到 18–20px（装饰性小图标可保持 14–16px），全站观感不再"碎"
2. **密度**：手机上加大行高与内边距，正文 12px → 13px、辅助 11px → 12px（桌面不变）
3. **后台表格**：手机上改为**卡片式列表**，桌面保留表格。优先三页：路线列表、用户列表、订单列表；其余三页（地点/在线/导入）先加横向滚动容器兜底

## 2. 不做什么

- 不改业务逻辑、字段、接口
- 不改桌面端表格样式（`md:` 以上保持现状）
- 不重做设计、不引 UI 库
- 不动 C 端的信息架构（只调尺寸/间距）

## 3. 现状证据（Harness 实测）

| 项 | 数据 |
|---|---|
| 图标尺寸分布 | `h-4 w-4` **201 处**、`h-3.5` 31 处、`h-5` 33 处、`h-6` 14 处 |
| 后台表格 | 6 页全部 `<table class="min-w-[860~960px]">`：Orders 960 / Places 860 / Users 880 / Online 880 / Imports 960 / Routes 920 |
| 结果页密度 | 地点行 `py-1.5`（上下 6px） |
| 手机端已达标项 | 横向溢出 0、小字号 0、小按钮 0（T-021/022 已修） |

## 5. 明确禁止

- 不得删除表格视图（桌面必须保留）
- 不得改 `min-w` 数值来"适配"（那会让桌面表格变形）
- 不得改字段语义、排序、筛选逻辑
- 不得整文件格式化
- 不得动 `md:` 以上的样式

## 6. 实施步骤

1. **C 端密度**：结果页/挑选页列表行手机端 `py-2.5`、`gap-3.5`；地点名 14→15px、辅助行 11→12px
2. **图标**：列表行内类型图标/序号、主操作按钮图标 16→18px（`h-[18px] w-[18px]` 或 `h-4.5`）；顶栏/导航保持
3. **后台卡片**（三页）：每页加 `md:hidden` 卡片列表 + `hidden md:block` 表格；卡片内容取该页最关键的 4–6 个字段
4. **其余三页**：表格外包 `overflow-x-auto` + `-mx-4 px-4`（手机上可横滑，不撑破页面）
5. 跑 `npm run audit:mobile` 确认无回归（溢出 0 / 小字号 0 / 小按钮 0）
6. 桌面 1440 截图确认表格仍在

- [ ] 结果页地点行在手机上明显更松（行高 ≥ 44px 触控友好）

- [ ] 后台路线/用户/订单三页：手机上显示卡片，桌面仍是表格
- [ ] 其余三页手机上可横向滚动且不撑破整页
