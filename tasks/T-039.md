# T-039 首页图标差异化 + 移除「本期新增」标记

> 用户 2026-10-24 16:09，附三张截图。

## 1. 目标

### ① 只改首页示意图标的图标（登录页保持不变）
- 现状：首页与登录页**共用** `SAMPLE_ROUTE.stationIconKeys = ['street','bowl','park','dumpling','shopping']`
- 问题：
  - `park` 的路径是"实心圆 + 树干"（`M12 2a9 9 0 1 0 .01 0z` + 小矩形），渲染成一个**白点**（截图里 3 号像空的）
  - `bowl`（2 号豆腐）与 `dumpling`（4 号饺子）形状接近，看着"重复"
- 要求：**首页 5 个图标两两不同**；**登录页保持现状不动**

### ② 移除「本期新增」类提示（全站）
用户明确：这类内部提示不要出现在产品界面上。

| 位置 | 内容 |
|---|---|
| `components/home/ImportCollectClient.tsx:284` | `badgeNew` 徽章 |
| `components/home/ImportCollectClient.tsx:287` | `badgePrd`（超出 PRD P0，待产品确认） |
| `components/route/TripSettingsFields.tsx:239/355/397` | 三处 `badgeNew` 徽章（出发城市/城际交通/住宿） |
| `components/route/RouteNewClient.tsx:236-241` | 黄色横幅「本期新增：出发城市 · 城际交通 · 终点城市住宿（超出原 PRD P0…）」 |
| `components/profile/ProfileMenu.tsx:40` | `collectedNewTag`（本期新增） |

移除后：**不再渲染**这些徽章/横幅；`messages.ts` 中对应 key 可保留（给历史文案留档）或一并删除，但**不得留下未使用且仍渲染的引用**。

## 2. 不做什么

- **不改登录页**（`LoginClient` 与其图标）
- 不改 Canvas 导出长图（保持序号）
- 不改任何业务逻辑、配额、接口
- 不动其它页面与图标（只改首页示意条 + 移除上述徽章）

## 3. 实现建议

1. 新增图标 key `tree`（真正的树：双层树冠 + 树干），**只给首页**用
2. 首页改用独立的 key 列表（不要复用 `SAMPLE_ROUTE.stationIconKeys`），例如：
   `HOME_SAMPLE_ICON_KEYS = ['street','hotpot','tree','dumpling','shopping']`
   —— street(1)/hotpot(2)/tree(3)/dumpling(4)/shopping(5) 形状两两不同
3. 登录页继续用 `SAMPLE_ROUTE.stationIconKeys`（保持 bowl/park/dumpling 不变）
4. 新增 `tree` 的 SVG path（实心、与其它 glyph 同为 24 viewBox，墨迹宽度 ≈18 单位）
5. 移除徽章与横幅的**渲染代码**（保留注释说明"按用户要求移除"）
