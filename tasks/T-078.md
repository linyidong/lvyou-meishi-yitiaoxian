## 1. 地图样式对齐（静态图）

现状：`requestStaticMap` 固定 `markers=mid,0xE11D48,:lng,lat;...` + 紫色 paths。
改为支持样式参数，并在免费分享海报生成时传入：
- `markers?: { lng; lat; label?: string; color?: string }[]`：每个点一个 marker 组（`mid,0xRRGGBB,label:lng,lat`，多组用 `|` 连接），label 取 1..9（>9 留空），颜色景点 `#14B8A6`、美食 `#F59E0B`；
- `lineColor?: string`：按天取色 `['#e11d48','#0d9488','#d97706','#4f46e5','#0284c7'][dayIndex%5]`；
- 不传时保持现有行为（`/api/amap/staticmap` 的会员导出路径不变）。
- `buildSharePosterMapImages` 按 snapshot 当天 place 的 type/顺序构造 markers 与 lineColor。

## 2. 去掉免费页顶部横幅

`components/share/SharePosterCard.tsx` 顶部 `<header>`（gradient + logo + 标题 + summary）删除；页面直接以海报卡片开始（保留 `px-4 pt-4` 的间距）。会员视图 `ShareViewClient` 的 header 不动。

## 3. 海报标题间距

`lib/route-poster.ts`：
- 新增 `TITLE_GAP = 18`；`headerH = HEADER_BASE_H + TITLE_GAP + titleLines.length * TITLE_LINE_H`；
- 标题基线 `titleY = HEADER_BASE_H + TITLE_GAP - 10`（logo 底 112 → 标题顶约 130，间距约 18px）；
- 信息区随 headerH 下移，不重叠。
