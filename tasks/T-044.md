# T-044 小红书「图片识别」：OCR → 文本 → 复用现有提取流程

> 用户 2026-10-24 第 3 条。凭证已在 `Project/.env.local` 配好并经 Harness 实测可用。

## 1. 目标

导入面板增加「图片识别」入口：
1. 用户选择一张图片（小红书笔记截图等）→ 前端上传 → 服务端调**腾讯云 OCR** → 返回识别文本
2. 识别文本**自动填入现有文本框**，用户点「AI 提取地点」继续走原有流程（收藏/建路线都复用，不新写一套）
3. **图片不落盘、不入库、不进 Storage**：只在内存中处理一次，响应不返回图片
4. UI 明确提示：「图片仅用于识别，不会保存」
5. 限制：单图 ≤ 7MB；每用户每日 OCR 次数上限（默认 20 次/日），超限给明确提示

## 3. 实现

### ① `lib/tencent-ocr.ts`（服务端）
- `export async function ocrImageBase64(base64: string): Promise<{ text: string; lineCount: number }>`
- TC3-HMAC-SHA256 签名（service `ocr`，host `ocr.tencentcloudapi.com`，action `GeneralBasicOCR`，version `2018-11-19`，region 读 env）
- 读 env 缺失时抛明确错误（`OCR_NOT_CONFIGURED`）
- 超时 20s；失败把腾讯云 `Error.Code/Message` 透传为可读错误
- 纯函数拆分：`buildAuthorization(...)` 可单测

### ② `app/api/ai/extract-image/route.ts`
- 仅登录用户（未登录 401）
- 接受 `multipart/form-data` 的 `file` 字段（或 JSON `{ imageBase64 }`，二选一实现，优先 multipart）
- 校验：MIME 为 image/jpeg|png|webp；大小 ≤ 7MB
- 每日限额：`user_daily_usage` 表 kind=`ocr`（沿用现有表结构；若不便则用内存/DB 简单计数并说明）
- 返回 `{ ok: true, text, lineCount }`；失败返回 `{ ok:false, code, message }`
- **不写任何文件/存储**

### ③ 前端（`ImportCollectClient`）
- 在「粘贴笔记文案 / 粘贴链接（抖音等）」旁边增加「图片识别」标签页
- 选择图片（`<input type="file" accept="image/*">`）→ 显示文件名与大小 → 点「识别图片」→ 转 base64 上传 → 成功后把文本**写入文本框**并提示「已识别 N 行，可点下方 AI 提取地点」
- 提示文案：「图片仅用于识别，不会保存」；超过 7MB/类型不符/超限 给明确提示
- 识别中禁用按钮 + loading

### ④ 文案
`config/messages.ts` 增加：图片识别标签、选择图片、识别中、识别成功、图片过大、类型不支持、每日上限、隐私提示、未配置提示

## 4. 不做什么

- 不改 `/api/ai/extract` 与 `/api/places`
- 不保存图片（不写 public/、不写 Storage、不写 DB）
- 不引入第三方 SDK（手写 TC3 签名，Node 内置 crypto）
- 不做批量多图
