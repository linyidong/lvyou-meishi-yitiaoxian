# T-043 AI 识别阶段即入库城市 + 「东山（东山岛）」显示名

> 用户 2026-10-24 20:22（第 2、3 条）。第 1 条（删除首页游客提示）已由 Harness 完成。

## 1. 目标

### ② 城市在**识别阶段**就入库，并展示给用户
- 现状：AI 识别返回 cityName，但城市**要到点「收藏地点」时**才由 `api/places` 的 `ensureCityInDb` 写入
- 改为：`/api/ai/extract` 识别出城市后**立即** `ensureCityInDb(city)`（复用已实现逻辑，抽到 `lib/city-ensure.ts` 供两处共用），响应里返回：
  - `cityName`（原名，如「东山」）
  - `cityId`
  - `cityIsNew`（本次新加入库为 true）
- 前端「收藏城市」区域**直接展示识别出的城市**（不再要求手动选择），并在新城市时标注「新城市，已加入城市库」
- 收藏时直接用该 cityId；`api/places` 仍保留 `ensureCityInDb` 作为兜底（幂等）

### ③ 显示名：「东山」→「东山（东山岛）」
- **不要改 `cities.name`**（会影响高德查询与拼音搜索）
- 新增显示别名机制：`config/cities.ts` 增加 `CITY_DISPLAY_ALIAS: Record<string, string> = { 东山: '东山（东山岛）' }` 与 `cityLabel(name)` 辅助函数（无别名时原样返回）
- 以下位置改用 `cityLabel()`：
  - 城市选择页的城市卡片标题（`CitySelectClient`）
  - 导入面板的「收藏城市」
  - 地点列表/路线里展示城市名的地方（如有）
- 搜索匹配仍按原名 + 拼音（可同时匹配别名里的「东山岛」）
