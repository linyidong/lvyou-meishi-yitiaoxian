# T-090 后台用户列表显示手机号账号

> 用户实测手机号注册成功，但后台「用户列表」看不到新手机号用户。

## 1. 根因

手机号账号在 `auth.users.phone`，`public.users.email = null`、`username = 手机号`。
后台用户列表：
- 邮箱列渲染 `u.email ?? '—'` → 手机号用户显示「—」；
- 表头仍写「邮箱」，看起来像没同步；
- 实际上 `public.users` 行已存在（`412cb009…`，username `13705963348`）。

## 2. 改动

- `app/admin/users/page.tsx`：`emailById` 回退 `username`（留痕里手机号用户不再显示 —）。
- `components/admin/AdminUsersClient.tsx`：邮箱列/卡片主标识 `u.email ?? u.username ?? '—'`。
- `config/messages.ts`：表头「邮箱 / 手机号」，搜索占位「搜索邮箱、手机号或用户名」。

## 3. 验收

- [x] 后台用户列表 6 行，含 `13705963348`（手机号账号，显示在「邮箱 / 手机号」列）
- [x] 搜索手机号可命中（username）
- [x] 桌面表格 + 手机卡片均生效
- [x] typecheck 0 / 113 单测 / E2E 8 (11.5s)

## 4. 说明

- 手机号注册链路本身正常：`auth.users` + `public.users` 都已写入；只是后台展示没回退。
- 手机号账号的邮箱列为空是预期（无邮箱），不是漏写。
