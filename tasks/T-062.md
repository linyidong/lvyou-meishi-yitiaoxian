# T-062 Windows 独立运行 + 文档四件套（补卡）

> 补记于 2026-11-08（T-064）。本任务在 2026-10-25 实施完成并提交（`83f3a63`），当时未建任务卡，现按事实补写，验收证据取自 `handover/阶段7-编码-交接摘要.md`。

## 1. 背景与目标

1. 项目原来只能「Mac 跑应用 + Windows 跑 Supabase」；用户要求 **Windows 单独一台机器也能跑起整个应用**。
2. 顺带修一个真实缺陷：**手机端埋点丢失**——前端以前直连 Supabase，手机上 `127.0.0.1` 指向手机自己。

## 2. 范围

### ① Windows 一键脚本（`windows/`）

| 文件 | 作用 |
|---|---|
| `启动项目.bat` | 查 Node → 查 `.env.local` → 查/启 Supabase（docker compose）→ `npm ci` / `next build` → `next start -H 0.0.0.0` → 打开浏览器 → 打印手机地址 |
| `停止项目.bat` | 结束 3000 端口进程 |
| `诊断.bat` | Node/npm/配置/依赖/Supabase/端口/局域网 IP/防火墙 体检 |
| `允许局域网访问.bat` | 管理员放行 3000 与 8000 |
| `创建桌面快捷方式.ps1` | 桌面生成启动/停止/诊断三个图标 |
| `config.bat` | 可选 `SUPABASE_DIR` |

### ② 埋点改同源

- 新增 `app/api/events/route.ts`：登录用户由服务端写 `events`；未登录不写；非法事件名忽略（返回 204）。
- `lib/events.ts` 改调同源 `POST /api/events`，不再前端直连 Supabase。

### ③ 文档

- 新增/更新 `docs/操作手册.md`、`技术栈文档.md`、`项目思维逻辑.md`、`面试题.md`、`docs/README.md`。
