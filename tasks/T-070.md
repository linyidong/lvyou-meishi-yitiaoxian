## 2. 设计要求（CSS 实现，不引入图片）

背景：靛蓝 `#1e1b4b` + 细点阵/网格 + 两团柔光（teal/rose 低透明度），可加一条极淡的虚线航线。

票面（白色/米白 `#fffdf8`，圆角 16–20px，`-rotate-3~-6deg`，大阴影）：
1. **顶部渐变条**：teal → amber → rose（与产品主色一致）。
2. **票头**：左侧小 logo（圆角方块 + 自绘路线折线/圆点）+ 产品名「旅行美食一条线」；右侧徽章「ROUTE PASS / 路线登机牌」。
3. **主标题**：`成都 · 吃喝一条线`（大号粗体，可两行）。
4. **四/五列信息区**：城市 `成都` / 天数 `2 天` / 地点 `16` / 交通 `步行` / 日期 `2026-11-08`（小字标签 + 粗体值，列间细竖线）。
5. **撕票线**：横向虚线 + 左右两侧半圆缺口（用与背景同色的圆覆盖模拟「打孔」）。
6. **副票区**：左侧条形码（竖线组）+ 票号 `No. 2026-11-08`；右侧 QR 示意（棋盘格 56–64px）+ 「扫码查看路线」。
7. **印章**：一枚斜置描边圆章「已出发 / DEPARTED」（rose 或 teal，透明度 80%），压在票面右下或中部。
8. 可选：票面左下角小字「TRAVEL FOOD LINE · CHENGDU」。

画面构图：票根略微倾斜、居中偏右；左上角仍是「一键导出，发给同行的人」+ 右上「导出长图」标签（保持现有位置），票根下方可加一行小字「登机牌风格 · 每天一张地图」。
