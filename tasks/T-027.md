# T-027 手机端三处调整：模块顺序 / 地图全屏 / 复位覆盖移除

> 用户 2026-10-23 22:24 提，附两张真机截图。三种模式（游客 / 普通 / 会员）规则一致。

## 1. 目标

### ① 挑选地点页：筛选列表在上，导入地点在下
- 现在：`导入地点`（AI 识别）面板在列表**上方**
- 要求：**`全部|景点|美食` 筛选 + 列表卡片在上；`导入地点` 面板在下**
- 游客页（`TryPickClient`）与会员/普通页（`RoutePlacesClient`）都要一致

### ② 调整路线页：地图可全屏、再点复位
- 点地图（或右上角「全屏」按钮）→ 地图占满视口（`fixed inset-0 z-50`）
- 再点一次 / 点关闭 / 按 ESC → 恢复原布局与原高度
- 切换后必须调 `map.resize()`，否则高德画布尺寸不对（显示错位）
- 两个结果页都要有（游客 `TryResultClient`、会员 `RouteResultClient`）

### ③ 一键复位：移除或调序后都出现，且复位到「最初系统安排」（含被移除的地点）
- 只要发生过**移除**或**调序** → 「一键复位」可见可点
- 复位后：地点集合与顺序 = **首次系统推荐结果**（被移除的地点**要回来**）
- 游客：零请求还原（points + legs + 总里程成对还原），并同步 sessionStorage
- 会员：还原并落库（`PUT /api/routes/[id]/places`），刷新后仍为原集合
- **注意**：T-026 曾把复位快照更新为"移除后的集合"（`TryResultClient.tsx:539-540`）——**本次要撤销该行为**，快照只在首次系统推荐/重新生成时更新，移除不得改快照

## 2. 不做什么

- 不改配额、计费、鉴权
- 不改排序手势与拖拽逻辑
- 不删现有「全屏之外」的地图功能（缩放按钮、图例、周边）
- 不动 admin

## 5. 明确禁止

- 不得让"复位"只恢复顺序而不恢复被删地点
- 不得让全屏后的地图尺寸错乱（必须 resize）
- 不得把导入面板直接删除（只是换位置）
- 不得改动 `/api/try/order` 与 places 接口契约
- 不得整文件格式化

## 6. 实施步骤

1. 两处挑选页：把列表区块移到导入面板之前（DOM 顺序调换，样式间距保持）
2. 结果页地图外层加 `mapFullscreen` 状态：`fixed inset-0 z-50 bg-white`；进入/退出后 `requestAnimationFrame` 内调 `map.resize()`
3. 触发方式：地图右上角「全屏」按钮 + 地图单击（非拖拽、非 marker）均可切换；全屏态显示「退出全屏」按钮并支持 ESC
4. 复位：撤销 T-026 对 `initialOrderRef` 的覆盖；`orderDirty` 判定同时覆盖"集合变化"与"顺序变化"
5. 会员页复位：还原后调 `PUT places` 落库（失败提示 + 回滚）
6. 补文案与测试
