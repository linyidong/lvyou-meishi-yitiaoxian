# T-050 设置页两处优化 + 技术栈页动态化

> 用户 2026-10-24 23:48（三张参考图，视觉参考仅供风格，内容必须用**本项目真实技术栈**）。

## 1. 目标

### ① 设置页「AI 模型」区：显示当前生效的 AI 模型
- 在该分组顶部加一块**只读摘要**（不是输入框），明确展示：
  - 「AI 提取地点：DeepSeek · `{deepseekModel}`」（如 `deepseek-chat`）
  - 「图片识别：腾讯云 OCR · `{ocrRegion}`」
- 让管理者一眼知道首页/导入用的到底是什么模型
- 修改输入框后，摘要同步更新（保存前显示"待保存"）

### ② 业务开关改成滑动开关（toggle）
- 现为原生 checkbox（截图里的黑色勾选框）
- 改为**滑动开关**：
  - 开启：**绿色**轨道 + 白色圆钮靠右 + **对勾**图标
  - 关闭：**灰色**轨道 + 圆钮靠左 + **叉号**图标
  - 带过渡动画（150–200ms），键盘可操作（`role="switch"` + `aria-checked`），可聚焦有 focus ring
- 三个开关（付费/图片识别/导入）统一

### ③ 技术栈页动态化（`/admin/tech-stack`）
- **不要静态罗列**：做成可交互、有动效的页面
- 内容必须为**本项目真实技术栈**（**不要照抄参考图里的 Go/MySQL/Vue**）：

| 分层 | 真实内容 |
|---|---|
| 前端 | Next.js 14（App Router）、React 18、TypeScript(strict)、TailwindCSS 3、lucide-react、Canvas 出图 |
| 服务端 | Next.js Route Handlers（API）、Node 运行时、Zod 风格手写校验、jose/cookie 会话 |
| 数据 | 自建 Supabase：PostgreSQL + GoTrue(Auth) + PostgREST、RLS、pg_cron、原子 RPC |
| 地图与算路 | 高德 JS API + Web 服务 Key 池、距离矩阵缓存、最近邻 + 2-opt 排序 |
| AI | DeepSeek（文案提取）、腾讯云 OCR（图片识别） |
| 质量与运维 | vitest（80）、Playwright（8 E2E）、移动端审计脚本、Nginx + SSH 隧道 + 每日 pg_dump |

- 交互与动效（至少实现 3 种）：
  1. **分层节点图**：左侧分层卡片，点击某层 → 右侧展开该层明细（含版本徽章），SVG 连线有流动动画
  2. **数字滚动**：如"80 单测 / 8 E2E / 14 张表"进入视口时数字递增
  3. **悬停高亮**：节点 hover 发光、连线高亮；点击明细条目展开一行说明
- 视觉：深色科技风（深石板底 + 项目主色渐变 `primary-from→primary-to` + teal 点缀），与项目其它页面协调
- 导航位置（**用户 2026-10-25 更正**）：技术栈放在**左侧边栏「设置」下方**（即 会员订单 → 设置 → 技术栈），不要放到顶部

## 2. 不做什么

- 不引入图表/动画库（用 CSS + SVG 手写；如必须用 CSS animation/keyframes）
- 不改设置页的字段与生效逻辑（T-049 已完成）
- 不改后台其它页面
- 不编造未使用的技术（如 Redis/MySQL/Go 一律不写）
