# T-037 图标细化：熊猫/购物/宫殿博物馆区分 + 放大可读性

> 用户 2026-10-24：图标仍重复（宽窄巷子=春熙路；大熊猫基地=太古里），且宝塔/宫殿要更有区分度。

## 1. 目标

1. 补齐语义类别，让**同一张图里的图标尽量不重复**
2. 解决 `palace` 与 `museum` 在 12–14px 下过于相似的问题（Trae 自己也提示了）
3. 图标略放大，小尺寸下可辨认

## 2. 需要新增/调整的 key

| key | 语义 | 关键词（优先级高于通用） | 实现 |
|---|---|---|---|
| `wildlife` | 动物园/熊猫/动物 | 熊猫 / 动物园 / 动物 / 海洋馆 / 水族馆 | lucide `PawPrint` 或自绘熊猫头 |
| `shopping` | 商场/商业街/购物 | 太古里 / 商场 / 购物 / 百货 / 广场 / 春熙路 / 步行街 | lucide `ShoppingBag` |
| `street` | 老街/巷子 | 街 / 巷 / 里 / 胡同 | lucide `Store`（保持） |
| `palace` | 宫殿/城门 | 宫 / 殿 / 城 / 府 / 苑 / 不夜城 | 自绘：**三层屋檐**（重檐），轮廓明显区别于展馆 |
| `museum` | 博物馆/展馆 | 博物馆 / 展馆 / 纪念馆 / 美术馆 | 自绘：**山墙+立柱**（单层三角顶+柱廊），不要与宫殿同构图 |
| `pagoda` | 塔 | 塔 / 寺 / 庙 / 禅 / 鼓楼 | 自绘：**多层塔身+塔尖**（保持） |

美食侧保持：`bowl` / `dumpling` / `skewer` / `hotpot` / `coffee`。

**匹配顺序**：wildlife → shopping → pagoda → palace → museum → park → street →（美食细分）→ 默认。
即「大熊猫基地」命中 wildlife 而不是 street；「太古里」「春熙路」命中 shopping。

## 3. 可读性

| 位置 | 现状 | 改为 |
|---|---|---|
| 首页 SVG | `r=13`，图标约 16px | `r=15`，图标 18px；序号角标保持可见 |
| 登录页海报 | `h-8 w-8` 圆 + 16px 图标 | 图标 18px；序号角标不小于 9px |
| Canvas 列表 | 26×26 圆角方块 | 30×30；图标 18px；序号徽标 10px 字 |
| Canvas 路径图 | 现有半径 | 半径 +2，图标 +3px |

## 4. 明确禁止

- 不得用 emoji
- 不得引入运行时图标库依赖（lucide 可复用 + 自绘 path）
- 不得改布局结构与文案
- 不得让同一张图里出现两个相同图标（语义确实相同的除外，如两条"街巷"）
