# T-067 我的路线：空路线缩略图占位 + 硬删除（数据库真删）

> 来源：用户 2026-11-08 走查第 3 条（截图：`我的路线` 里有一条 0 个地点的路线，缩略图是空网格 + 提示「这些地点还没有坐标…」，且无法删除）。
> 归属：Trae 实施，Harness 验收。

## 1. 目标

1. **空路线缩略图**：`placeCount === 0` 的路线卡片，缩略图位置改为明确的空态——显示「没有任何地点的路线」+ 一句引导（如「继续调整添加地点，或删除这条空路线」），不再显示高德空网格/「这些地点还没有坐标」。
2. **删除功能**：卡片增加「删除」按钮，二次确认后**硬删除**（数据库 `DELETE`，`route_places`/`route_shares` 由外键级联），删除成功即从列表移除。

## 2. 修改范围

- `Project/app/api/routes/[id]/route.ts`：新增 `DELETE`
- `Project/components/route/MyRoutesClient.tsx`：空态缩略图 + 删除按钮 + 确认弹窗 + 局部移除
- `Project/config/messages.ts`：新增删除/空态文案
- 可复用 `Project/components/common/ConfirmDialog.tsx`
- **不改**：`routes` 表结构、RLS 策略、分享/导入逻辑、其他页面。

## 3. 实现要点

### ① DELETE API
- 仅登录用户（未登录 401）；
- 先按 `id + user_id` 查存在（不存在/非本人 → 404，不泄露他人数据）；
- 用**用户态 client** 删除（RLS `routes_delete_own` 已存在），不要用 service_role；
- 失败 → 500 + `MESSAGES.NETWORK_ERROR`；成功 → `{ ok: true }`。

### ② 卡片空态
- `r.placeCount === 0` 时不渲染 `AmapMap`，渲染固定高度的空态块（保持卡片高度一致）：
  - 图标（如 `RouteOff` / `MapPinOff`）+ 「没有任何地点的路线」+ 引导小字；
  - 城市标签、交通标签保留原位。

### ③ 删除交互
- 「删除」按钮放在两个操作按钮下方（红色描边/文字，全宽或右对齐），或与操作同排但视觉弱化；手机上不小于 40px 高；
- 点击弹 `ConfirmDialog`：标题「确认删除这条路线？」，描述含路线名 + 「删除后不可恢复」；
- 确认后 `DELETE /api/routes/{id}`：成功 → 本地移除卡片（`router.refresh()` 兜底）；失败 → 顶部/卡片内错误提示，不静默；
- 删除中按钮禁用 + 「删除中…」。

### ④ 文案
`MESSAGES.MY_ROUTES` 新增：`emptyThumbTitle`、`emptyThumbHint`、`delete`、`deleting`、`deleteTitle`、`deleteDesc(title)`、`deleteConfirm`、`deleteFailed`（命名可微调，但必须集中放 messages）。
