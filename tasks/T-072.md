# T-072 截图模式：退出按钮移到原「截图模式」工具条位置

> 来源：用户 2026-11-08 20:50 反馈（截图 1/2）：进入截图模式后，工具条整个消失，退出按钮跑到页面底部大框里；希望在**原来「截图模式」按钮的位置**（右上角）显示「退出截图模式」，手机同样位置，便于一眼看到和及时操作。

## 1. 现状

`components/route/RouteResultClient.tsx`：
- 工具条 `{shot ? null : (...)}`：截图模式下整条工具条隐藏；
- 页面底部 `{shot ? <div className="mt-4 text-center">...提示...退出按钮...</div> : null}`。

## 2. 目标

1. 截图模式下，在原工具条的**右上角位置**显示「退出截图模式」按钮（与「截图模式」按钮同一位置/对齐）；
2. 桌面：左侧可保留一行灰色截图提示（`M.shotTip`，小字），右侧退出按钮；手机：只显示右上角退出按钮（提示可隐藏，避免挤压）；
3. **删除页面底部那块提示 + 退出按钮**（避免重复、避免把页面撑高）；
4. 其它工具条按钮（调整/导出长图/保存路线）在截图模式下仍隐藏，保证截图干净；
5. 手机 390：退出按钮可见、不溢出、位置在内容右上角（与原工具条同列）。

## 3. 修改范围

- 仅 `Project/components/route/RouteResultClient.tsx`（必要时 `config/messages.ts` 文案）。
- 不改截图模式以外逻辑、不改地图/列表/分享/保存，不动游客页（TryResultClient）。
