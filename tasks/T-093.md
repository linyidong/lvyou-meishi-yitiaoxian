## 1. 改动

- 云机装 Docker（腾讯云镜像加速 `mirror.ccs.tencentyun.com`），`/srv/supabase/docker-compose.yml` 跑 postgres 15.8.1.135 / gotrue v2.196.0 / postgrest v12.2.3 / kong 2.8.1，只暴露 `127.0.0.1:8000`（Kong）与 `127.0.0.1:5432`。
- Kong 声明式配置启用 `key-auth`（无 apikey → 401，与旧栈一致）；`kong.yml` 权限 644（容器内非 root）。
- 数据迁移：Windows `pg_dump`（2,441,716 字节）→ 一次性 HTTPS 上传通道 → 临时库演练 → 正式库恢复 → 修 `auth` 属主 + public 授权 → 重建 `expire-members` cron。
- 应用：换新 `NEXT_PUBLIC_SUPABASE_ANON_KEY` / `SUPABASE_SERVICE_ROLE_KEY`（JWT 密钥轮换，用户需重登）→ 重建 → 重启；Nginx `/rest` `/auth` 从 `8081`（隧道）改 `8000`；隧道停用。
- 备份：`/srv/backup/backup.sh` + `lyytx-backup.timer`（每日 04:00，保留 14 份）。
