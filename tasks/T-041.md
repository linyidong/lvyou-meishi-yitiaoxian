# T-041 分享导入：首页入口 + 双模式导入 + 我的路线分区

> 用户 2026-10-24 17:17（第 1 条）+ 追问确认：**C 方案（两种都支持）**，且「我的路线」页要**单独一个「会员分享路线」模块**。

## 1. 目标

1. 首页「开始排路线 / 我的路线」右侧新增 **「导入分享路线」** 按钮
   - 会员（`member=true` 或 `role=admin`）：可点，打开导入弹层
   - 正常用户（非会员）：**灰色禁用**，提示「会员可用该功能」
2. 导入弹层：粘贴**分享链接**（长图二维码里就是这条链接；也接受纯 token）→ 选择模式：
   - **建成我的路线**：在自己账号下新建路线（复制快照全部地点），并标记 `imported_from`
   - **只收藏地点**：只把快照地点写进自己的**收藏夹**（`places.is_collected=true`），**不建路线、不占路线额度**
3. 「我的路线」页拆两个模块：
   - **我的路线**（`imported_from` 为空）
   - **会员分享路线**（`imported_from` 非空；为空时不显示该模块）

## 3. 需要改动

### ① 接口支持双模式
`app/api/shares/[token]/import/route.ts`：
- 读 body `{ mode?: 'route' | 'places' }`，默认 `'route'`
- `route`：保持现有行为，额外写 `imported_from: params.token`；仍占用路线额度
- `places`：只做 place find-or-create + 写 `is_collected=true`；**不建 route、不占路线额度**；返回 `{ ok, mode, placesCount }`
- 两种模式都要求会员/admin（现状保留）

### ② token 解析工具
新增 `lib/share-token.ts`：`parseShareToken(input: string): string | null`
- 支持 `https://host/share/<token>`、`/share/<token>`、纯 token
- 忽略 query / hash / 首尾空格
- 纯函数 + 单测（3 个正例、2 个反例）

### ③ 首页按钮
`components/home/HomeClient.tsx`：已有「开始排路线」「我的路线」；新增第三个按钮
- 需要判断当前用户是否会员：页面已能拿到 `user`，请把 `isMember` 传进来（`member || role==='admin'`）
- 非会员：`<button disabled>` 灰 + `title`/旁边小字「会员可用该功能」

### ④ 导入弹层（新组件）
`components/share/ShareImportDialog.tsx`（客户端）：
- 输入框：粘贴分享链接或 token
- 两个模式单选（建成我的路线 / 只收藏地点），带一句说明
- 提交：解析失败提示；成功提示"已导入 N 个地点 / 已生成路线"，给「去我的路线」链接
- 关闭/取消；提交中禁用按钮

### ⑤ 我的路线分区
- `app/(user)/routes/page.tsx`：select 增加 `imported_from`，传给 `MyRouteItem`
- `components/route/MyRoutesClient.tsx`：拆两组渲染；「会员分享路线」模块仅当有数据时出现
- 类型 `MyRouteItem` 增加 `importedFrom?: string | null`

### ⑥ 文案
`config/messages.ts` 增加导入相关文案（按钮、弹层、两种模式说明、成功/失败、会员限定提示）。

## 4. 不做什么

- 不做二维码图片解码（二维码内容就是分享链接，粘贴链接即可；如后续要扫码再另立任务）
- 不改分享页展示逻辑（非会员只看海报）
- 不改会员配额规则（导入建路线仍占额度）
- 不新增第三方依赖
