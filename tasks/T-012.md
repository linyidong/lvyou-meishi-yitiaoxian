# T-012 修复 build 阻塞：非 Hook 函数误用 use 前缀

> 由 Harness 起草。来源：`docs/progress.md` 阻塞项（2026-10-21 01:26 记录）+ Harness 实跑 `next lint` 复核。

## 1. 目标

让 `npm run build` 能通过：消除 `react-hooks/rules-of-hooks` 的 Error（它会让 `next build` 的 lint 阶段失败）。

## 2. 不做什么

- 不改任何业务逻辑、不改样式、不改文案
- 不动另外 3 个 warning（属既有技术债，不在本任务）
- 不通过 `eslint-disable` / 改 ESLint 配置 / 关规则来"绕过"
- 不改 `package.json`、不升级依赖

## 3. 背景与依据

- 报错原文（Harness 实跑 `npx next lint`）：
  ```
  ./components/home/ImportCollectClient.tsx
  374:32  Error: React Hook "useSample" cannot be called inside a callback.
          react-hooks/rules-of-hooks
  ```
- 根因：`Project/components/home/ImportCollectClient.tsx:111` 定义了 `function useSample(i: number)`，**它只是个普通函数，不是 Hook**；但 `use` 前缀让 ESLint 按 Hook 规则校验，而它在 `:374` 的 `() => useSample(i)` 回调里被调用 → 判定"回调里调 Hook"。
- 影响：`next build` 默认在构建时跑 lint，Error 会中断构建 → 阶段 8 上线被卡。
- 来源提交：`fa7d4ac`（早于本次接手，非本期改动引入）。

## 4. 涉及模块与允许修改的文件

| 文件 | 允许的改动 |
|---|---|
| `Project/components/home/ImportCollectClient.tsx` | 把 `useSample` 重命名为 `applySample`（定义 1 处 + 调用 1 处） |
| `docs/known-issues.md`、`docs/progress.md` | 同步状态 |

## 5. 明确禁止的变更

- 不得改函数体逻辑（三行 setState 原样保留）
- 不得改按钮 onClick 的行为
- 不得顺带修 warning、不得格式化文件
- 不得加 `// eslint-disable-next-line`
- 不得改 ESLint / next 配置

## 6. 实施步骤

1. `Project/components/home/ImportCollectClient.tsx:111` `function useSample(` → `function applySample(`
2. `:374` `onClick={() => useSample(i)}` → `onClick={() => applySample(i)}`
3. 全文件 grep 确认无残留 `useSample`
4. `npm run lint`（期望 0 error）
5. `npm run build`（期望成功，且仍只有原 3 个 warning）
6. 若 build 生成了 `.next` 产物，属正常，不需清理（已在 `.gitignore`）
