# T-047 首页示意图：地名上图标 + 登录后跳首页

> 用户 2026-10-24 22:43（第 1、2 条）。

## 1. 目标

### ① 首页右侧示意图：把底部清单的地名，按顺序标到对应点位旁
- 现状：底部是 `<ol>` 清单「1 宽窄巷子 / 2 陈麻婆豆腐 / 3 人民公园 / 4 钟水饺 / 5 春熙路」（用户截图红框），图上只有图标+序号（黑框位置）
- 改为：**把 5 个地名直接标在每个点位旁**（对应黑框位置），底部清单删除（避免重复）
- 字体要求：**正常大小、好看**（不要现在这种过小的字）
  - SVG `viewBox="0 0 300 180"`，建议 `fontSize` 11–12（渲染后约 20px），`fontWeight` 500–600，白色/浅色但对比足够
  - 标签与点位、虚线不要重叠：按点位分布分别放在点的上方/下方（如 1、5 放上方，2、4 放上方偏高，3 放下方），必要时加半透明深色底衬
- 图例（景点/美食）与「约 4.1 公里 · 55 分钟」保留
- 手机端（<640px）也要能看清，不能压线/溢出

### ② 登录后跳首页
- 现状：`LoginClient` 登录成功后 `router.replace(data.redirect ?? (isAdmin ? ROUTES.ADMIN_HOME : ROUTES.PROFILE))`
- 改为：**非管理员一律跳首页**（`ROUTES.HOME`），管理员仍跳后台
- 有 `redirect` 参数时仍优先用 redirect（如从分享页/受保护页跳登录的场景）
- **注册成功**同样跳到首页（检查注册分支是否复用同一处）

## 2. 不做什么

- 不改首页其它区块（导入面板、按钮）
- 不改示例路线的数据与坐标
- 不改后台登录跳转
