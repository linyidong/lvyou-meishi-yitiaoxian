# T-051 业务开关：说明文案补全 + 前端关闭态提示

> 用户 2026-10-25 第 1 条。拆分为 3 个小任务中的第 1 个。

## 1. 目标

1. 设置页「业务开关」三个开关的说明文案统一口径：**既说明接口 403，也说明前端会怎么提示**
   - 开放付费：`关闭后下单接口返回 403，收银台提示「暂停购买」`
   - 图片识别：`关闭后图片识别接口返回 403，首页/导入面板的图片识别入口提示「已暂停」`
   - 导入地点：`关闭后导入接口返回 403，首页导入面板提示「已暂停」并禁用入口`
2. **前端真的要有提示**（不能只靠接口 403）：
   - 首页导入面板（`ImportCollectClient`）：
     - `importEnabled=false`：面板顶部显示提示条「导入地点功能已暂停」，文本输入、图片识别、AI 提取、收藏按钮**禁用**
     - `ocrEnabled=false`：图片识别标签页显示「图片识别功能已暂停」，选择/粘贴/识别按钮禁用
   - 收银台（`MemberCard`）：`billingEnabled=false` 时购买区显示「暂停购买」提示（若现有已覆盖则确认即可）

## 2. 数据通路

- `app/(user)/page.tsx` 服务端读取 `getAppSettings()`，把 `{ importEnabled, ocrEnabled, billingEnabled }` 传给 `HomeClient` → `ImportCollectClient`
- 个人中心的 `MemberCard` 由服务端页面传 `billingEnabled`（或复用现有 props）

## 3. 不做什么

- 不改设置页布局与保存按钮（T-052）
- 不改 AI 模型可配置（T-053）
- 不改接口 403 逻辑（已生效）

## 4. 验收标准

- [ ] 三个开关的说明文案都写清"接口 403 + 前端提示"
- [ ] 关闭「导入地点」→ 首页导入面板出现「已暂停」提示条，输入/识别/收藏均禁用
- [ ] 关闭「图片识别」→ 图片识别标签页出现「已暂停」，按钮禁用
- [ ] 关闭「开放付费」→ 个人中心购买区显示暂停提示
- [ ] 恢复后所有入口恢复正常（刷新页面）
- [ ] `typecheck` 0、`test:run` 全过、`test:e2e` 8 条通过
- [ ] 改完重启 dev 再截图（A8）
