# T-026 结果页支持「移除已选地点」

> 用户 2026-10-23 反馈：结果页能调顺序，但**不能移除已勾选的地点**，选错只能回列表取消，体验断裂。

## 1. 目标

结果页（游客 + 会员）每个地点行提供「移除」，移除后：
- 列表即时减少该行、序号重排
- **里程/时间重新计算**（不能保留旧的分段数据）
- 剩余不足下限时禁止移除并提示
- 游客：草稿同步（sessionStorage），刷新不复活
- 会员：落库（原子替换），失败则回滚并提示

## 2. 不做什么

- 不改后端接口契约（复用 `/api/try/order` 与 `PUT /api/routes/[id]/places`）
- 不改排序交互（拖拽/上下移/移号保持）
- 不改配额与计费
- 不动 admin

## 3. 现状证据（Harness 实测）

| 项 | 现状 |
|---|---|
| `components/try/TryResultClient.tsx` | 有 `reordering`、上移/下移/移号；`grep "移除\|删除"` → **0 处** |
| `components/route/RouteResultClient.tsx` | 同上，无移除 |
| `/api/try/order` | 接受 `points` 数组，校验 `GUEST_TRY_MIN_PLACES <= len <= GUEST_TRY_MAX_PLACES` → **可传子集** |
| 会员保存 | T-020 已改为 `PUT /api/routes/[id]/places`（单事务原子替换）|

## 4. 涉及模块与允许修改的文件

| 文件 | 改动 |
|---|---|
| `Project/components/try/TryResultClient.tsx` | 行内「移除」按钮 + 子集请求 + 草稿同步 + 失败回滚 |
| `Project/components/route/RouteResultClient.tsx` | 同上，落库走 PUT places |

## 5. 明确禁止

- 不得只删本地数组而不重算里程（会显示错误距离）
- 不得在剩余 < 下限时仍允许移除
- 不得吞掉接口失败（失败必须回滚 UI 并提示）
- 不得改 `/api/try/order` 的最小/最大限制
- 不得整文件格式化

## 6. 实施步骤

1. 结果页每行加「移除」：`aria-label="移除该地点"`，与上移/下移同组
2. 点击：从当前列表过滤 → 若剩余 < `GUEST_TRY_MIN_PLACES`(2) → toast 提示并 return
3. 游客：调 `/api/try/order`（points=剩余地点）→ 用返回结果替换 state + 写 sessionStorage；失败则恢复原数组并提示
4. 会员：先乐观更新 UI → `PUT /api/routes/[id]/places`（剩余 items）→ 成功后重算（复用现有 `/api/amap/route` 或后端返回）→ 失败回滚
5. 游客页「一键复位」逻辑保持可用（移除后复位应回到"当前剩余集合"的系统顺序）
6. 补测试与文案

## 7. 验收标准

- [ ] 游客结果页：移除 1 个 → 行数 -1、序号连续、总里程变小、刷新不复活
- [ ] 剩余 2 个时「移除」禁用/提示，无法降到 1
- [ ] 会员结果页：移除 1 个 → 落库成功（刷新后仍为移除后的集合）
- [ ] 接口失败时 UI 回滚 + 明确提示（不静默）
- [ ] 排序（拖拽/上下移/移号）、一键复位、保存路线均不回归
- [ ] `npm run typecheck` exit 0、`npm run test:run` 全过
- [ ] 不跑 build
