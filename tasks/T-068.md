# T-068 首页右侧示意区：自动轮播（路线示意 + 地图路线 + 美食景点）

> 来源：用户 2026-11-08 走查第 4 条（截图红框：首页右侧「成都 · 第 1 天 · 步行」示意区）。要求「保持当前显示不变，改成自动轮播，可以添加地图路线页面展示，再加一些美食景点作为展示」。
> 归属：Trae 实施，Harness 验收。

## 1. 目标

把首页右侧 `bg-teal-900` 示意卡改成 **3 屏自动轮播**，首屏与现在完全一致：

| 屏 | 内容 | 说明 |
|---|---|---|
| 1 | 现有路线示意（5 个点位 + 虚线 + 地名 + 图例 + 里程） | **保持现有 DOM/SVG 视觉不变**，原样作为第 1 屏 |
| 2 | 「地图路线」展示 | 结果页地图的示意版：浅色地图底 + 道路线 + 路线折线 + 编号点位 + 底部「约 4.1 公里 · 55 分钟」+ 右上角标签「路线地图」 |
| 3 | 「美食景点」展示 | 4 个卡片（宽窄巷子 / 陈麻婆豆腐 / 大熊猫基地 / 钟水饺），用 `PlaceGlyph` 图标 + 名称 + 景点/美食小标签，右上角标签「收藏夹」 |

交互要求：
- **自动轮播 5 秒/屏**；底部圆点指示器（可点击切换）；
- **鼠标悬停/键盘聚焦时暂停**，移出恢复；
- `prefers-reduced-motion: reduce` 时**不自动轮播**（仍可点圆点）；
- 切换用淡入/淡出（≤400ms），**不产生布局跳动**（容器高度固定，与现有一致）；
- 移动端（390px）与桌面（1440px）都不溢出、文字不重叠；
- 不引新依赖、不用外链图片/emoji。

## 2. 修改范围

- `Project/components/home/HomeClient.tsx`
- `Project/config/messages.ts`（轮播文案/标签/站点数据，集中管理，不写死在组件）
- 如需动画 keyframes 可加 `Project/app/globals.css`（带 `prefers-reduced-motion` 关闭）
- **不改**：登录页海报、首页其它区块、路由/接口/数据库。

## 3. 实现要点

1. 抽出 `SAMPLE_ROUTE` 的数据使用方式：第 1 屏沿用 `MESSAGES.SAMPLE_ROUTE`（stations / homeStationIconKeys / distance / legend），不得改写这些数据；
2. 第 2 屏地图用**纯 SVG/CSS 绘制**（道路可用细线网格/折线，路线用现有粉色虚线风格 `#fda4af`，点位圆用 teal/amber），不调用高德、不加载图片；
3. 第 3 屏 4 个卡片用 `PlaceGlyph`（已有组件）+ `MESSAGES.SAMPLE_ROUTE.stations` 前 4 个 + `stationTypes` 判定景点/美食配色；
4. 轮播状态：`const [slide, setSlide] = useState(0)` + `useEffect` 定时器（5s），`paused` 由 `onMouseEnter/Leave`、`onFocus/Blur` 控制，reduced-motion 用 `window.matchMedia` 判断；
5. 圆点：`button` + `aria-label`（第 N 屏）+ `aria-current`；容器加 `role="group"` + `aria-roledescription="carousel"`；
6. 不加 `aria-live`（自动轮播会打断读屏）。
