# T-080 分享海报地图去掉半透明填充多边形

> 来源：用户 2026-11-08 23:18 截图：分享海报地图中间出现一大块青绿色「涂层」，路线页地图没有。

## 1. 根因

`lib/amap.requestStaticMap` 的 `paths` 参数写成：
`6,<lineColor>,1,<lineColor>,0.2:<coords>`
高德静态图 paths 的第 4/5 位是**填充色 / 填充透明度**，0.2 让首尾相连的折线被填成半透明多边形。

## 2. 改动

- 改为 `6,<lineColor>,1,<lineColor>,0:<coords>`（填充透明度 0），只画线不填充；
- `share-poster-map` 缓存 key 升 `v6`，避免旧填充图命中；
- 其它（编号、配色、地名标签、fit zoom、会员导出）不变。
