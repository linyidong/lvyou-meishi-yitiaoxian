# T-007 F-52 分享分级：非会员只看到路线图片

> 由 Harness 起草，与 `docs/implementation-plan.md` T-007 对应。用户已批准计划（G5）。
> 用户口径（Q10）：非会员/游客打开分享链接**只看到路线图片**；会员可看完整路线并导入。
> 用户口径（本任务追加确认）：图片**露出地点名与顺序**。

## 1. 目标

`/share/[token]` 按访问者身份分两套渲染：
- **会员**：现状不变（完整路线 + 导入按钮）
- **非会员 / 游客**：只看到「路线海报卡片」（标题/城市/天数/每天地点名与顺序/二维码 + 升级引导），**服务端不下发**坐标、地址、placeId、导航链接等可被滥用的完整数据

## 2. 不做什么

- 不改会员视图的任何行为与样式
- 不改 `shares/[token]/import` 接口（它已有 `tier === 'free'` → 403）
- 不引入新依赖（不引 node-canvas / satori；海报沿用客户端 canvas `renderRoutePoster`）
- 不做服务端 PNG 生成
- 不改分享生成端（`RouteShareButton`）
- 不动 RLS、不动 `route_shares` 表结构

## 3. 背景与依据

- PRD：`docs/项目需求文档PRD.md` §4.1 新增-F52、§6、§5 第 4 条
- 现状：`Project/app/share/[token]/page.tsx` 用 `createAdminClient` 直查 `route_shares` 快照，把完整 snapshot 交给 `ShareViewClient`
- 已有能力：`Project/lib/route-poster.ts:99 renderRoutePoster()`（客户端 canvas，画品牌条 + 标题 + 每天地点 + 二维码，**不调高德静态图**）
- 安全要点：**只在服务端裁剪数据**。若把完整 snapshot 传给客户端再"隐藏显示"，F12 即可读到，等于没做付费墙。

## 4. 涉及模块与允许修改的文件

| 文件 | 允许的改动 |
|---|---|
| `Project/components/share/ShareViewClient.tsx` | 拆出/新增「非会员海报视图」分支或独立组件 |
| `Project/app/share/[token]/page.tsx` | 按身份取最小字段，分渲染 |
| 可选：`Project/components/share/SharePosterCard.tsx`（新建） | 海报样式卡片 + 「保存为图片」按钮 |
| `Project/config/messages.ts` | 新增升级引导与图片相关文案 |
| `docs/feature-status.md`、`docs/open-questions.md`(Q-011)、`docs/progress.md` | 同步 |

## 5. 明确禁止的变更

- 不得把完整 snapshot（含 lat/lng/address/placeId）传给非会员分支的 props
- 不得改会员视图的数据与行为
- 不得引新依赖、不得动 `package.json`
- 不得改 `/api/shares/[token]/import` 的鉴权语义
- 不得为了"看起来是图片"而内嵌完整 JSON

## 6. 实施步骤

1. `page.tsx`：取到 snapshot 后判定 `isMember`（复用 `getQuotaProfile`/`isMemberActive` 口径）
2. 非会员分支：**构造最小视图模型**（仅 `title / cityName / days / totalPlaces / dayPlans[{dayIndex, places[].name}] / token 生成的二维码链接`），丢弃坐标、地址、id
3. 渲染海报样式卡片（视觉与 `renderRoutePoster` 一致：品牌条、标题、每日 pill、地点行、二维码位、底部升级按钮）
4. 「保存为图片」按钮：用同一份最小数据调 `renderRoutePoster` 出 PNG 下载（可选，若成本高可后置并在汇报注明）
5. 升级引导按钮跳 `/profile`（未登录跳 `/login?redirect=/share/<token>`）
6. typecheck + build + 起 dev 用 curl 抓非会员页面 HTML，**grep 确认其中不含 `lat`/`lng`/`address`**

## 7. 验收标准

- [ ] 游客（未登录）打开 `/share/<token>`：只看到海报卡片 + 升级引导，**拿不到完整路线**
- [ ] 非会员（免费档登录）同上
- [ ] 会员打开：与现状完全一致（完整路线 + 导入按钮可用）
- [ ] 非会员页面 HTML 中 `grep -c "lat\|lng\|address"` = 0（服务端未下发）
- [ ] 导入接口行为不变：非会员调 `/api/shares/[token]/import` 仍 403
- [ ] `npm run typecheck` exit 0、`npm run build` 成功
- [ ] 会员视图零回归（人工对比）

## 9. 人工验收

1. 用会员分享一条路线拿到链接
2. 退出登录打开链接 → 应只见海报卡片 + 「升级会员可导入」
3. 用非会员账号打开 → 同上
4. 用会员账号打开 → 完整路线 + 导入可用
