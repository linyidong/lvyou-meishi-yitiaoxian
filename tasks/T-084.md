# T-084 修复「我已完成付款」无反应 + 重复待核销订单

> 来源：真实用户在 `18960133530@qq.com` 付款后点「我已完成付款」无反应（截图显示「你已有待核销的订单…」）。

## 1. 根因

1. `POST /api/member/orders` 调 `create_member_order_guarded` 成功后返回 `orderId: data.id`；
   RPC 实际返回 `{result, order_id}`，**没有 `id`** → 响应 `{ok:true}` 但无 `orderId`。
2. 前端 `submitOrder` 判断 `!data.orderId` 即报错，停留在收银台表单，用户看不到成功/等待态 → 再次点击。
3. `MAX_PENDING_ORDERS=2` 允许同一用户存在 2 笔待核销，于是产生两笔 pending；
   之后再点就被「已有待核销订单」拦截，表现为「没有反应」。

## 2. 修复

- `app/api/member/orders/route.ts`：
  - `orderId: res.order_id`；
  - 同一用户 + 同套餐 + 同通道已有 pending → 直接返回该 `orderId`（`alreadyPending:true`），不再新建。
- `components/profile/MemberCard.tsx`：
  - `PendingOrderInfo` 增加 `id`；
  - 已有待核销订单时点「升级为会员」直接进「等待核销」态；
  - `submitOrder` 若已有 pending，直接进等待态，不再发第二次请求。
- `app/(user)/profile/page.tsx`：查询 pending 订单时带 `id`。

## 3. 真实订单处理（用户已确认付款）
