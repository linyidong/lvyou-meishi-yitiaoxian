# T-021 移动端体验专项（地图 / 字号 / 触控 / 横向滚动）

> 由 Harness 起草。来源：用户 2026-10-22 反馈「手机不能自适应，有的地方要放大，比如地图」，四项都有。
> 度量工具：`Project/scripts/mobile-audit.mjs`（`npm run audit:mobile`，Playwright 模拟 iPhone 16 Pro / Redmi K80）。

## 1. 目标

在 402×874（iPhone 16 Pro）与 412×915（Redmi K80）下：
1. **地图**：手机上高度足够（≥45vh）、双指缩放可用、不再"看不清"
2. **字号**：正文/说明 ≥12px，徽章类 ≥11px
3. **触控**：可点元素 ≥40px（关键按钮 ≥44px）
4. **横向滚动**：公开页面 0 横向溢出；`/city` 的城市芯片行在手机上不再需要"左右拖"

## 2. 不做什么

- 不改桌面端视觉（一律用 `md:`/`sm:` 断点包住改动）
- 不改业务逻辑、接口、配额
- 不引 UI 框架、不重做设计
- 不动 admin 后台布局（本期只做 C 端；后台另议）

## 5. 明确禁止

- 不得改动 `md:` 以上的桌面样式
- 不得改业务逻辑与接口
- 不得通过 `transform: scale` 或改 viewport 来"假装适配"
- 不得整文件格式化；不得动 admin 页面

## 6. 实施步骤

1. 地图：`AmapMap` 增加 `touchZoom: true`（显式），并确认 `dragEnable/zoomEnable` 仍跟 `interactive`
2. 两个结果页：地图容器类名改为响应式高度（手机 45vh，桌面维持 320/380 现状）
3. 顶栏与登录页：可点元素高度提到 ≥40px（关键按钮 44px）
4. `/city` 芯片行：手机 `flex-wrap`，桌面保留横向滚动
5. 字号：把正文级 10–11px 提一档（徽章 10→11，正文 11→12）
6. 跑 `npm run audit:mobile` 前后对比，贴输出

## 7. 验收标准

- [ ] `npm run audit:mobile`：**横向溢出 0**，**小字号 0**（正文级），**小按钮 0**
- [ ] 地图在手机上高度 ≥45vh 且 ≤60vh；桌面不变
- [ ] `/city` 手机上芯片换行，无横向拖动
- [ ] 桌面 1440 宽截图与改前一致（人工比对关键页）
- [ ] `npm run typecheck` exit 0、`npm run test:run` 30 passed
- [ ] 不跑 `npm run build`（dev server 在服务）

## 9. 人工验收

用户用 iPhone 16 Pro 与 Redmi K80 各走一遍：首页 → /city → /try/new → /try/pick → /try/result，重点看地图能否双指缩放、文字是否清楚、按钮是否好点。

## 10. 失败恢复

`git revert <commit>`；纯样式改动，无数据影响。

## 11. 风险等级

**低**。但改动面广（多个组件），需回归桌面端。
