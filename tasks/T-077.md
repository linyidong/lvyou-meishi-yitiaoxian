# T-077 免费分享海报：服务端生成静态地图（带缓存），修复「地图暂不可用」

> 来源：2026-11-08 走查 05。匿名分享页海报里的地图区域显示「地图暂不可用」。
> 根因：海报由客户端 `renderRoutePoster` 调 `/api/amap/staticmap`，该接口要求登录；匿名 401 → 占位框。
> 用户选择方案 A：**服务端用 Key 池生成静态地图（带缓存），把图片 data URL 传给海报**，免费海报显示真实地图，且客户端仍然拿不到坐标。

## 1. 目标

1. 匿名/非会员打开 `/share/[token]`，海报中每天的地图显示**真实静态地图**（不再「地图暂不可用」）；
2. 坐标/地址不下发到客户端：只传 base64 data URL；免费视图的 `SharePosterView` 仍无 lat/lng/address；
3. 同一 token 的静态地图**缓存**（进程内，TTL 6 小时），重复打开不重复消耗高德额度；
4. 会员分享视图、失效/撤销提示、升级 CTA 等行为不变；
5. 生成失败仍降级为占位框，不阻断海报。

## 2. 实现

### ① 新增 `Project/lib/share-poster-map.ts`（仅服务端引用）
- `export async function buildSharePosterMapImages(snapshot: RouteShareSnapshot, cacheKey: string): Promise<(string|null)[]>`
- 对 `snapshot.dayPlans` 每天：筛出 `lat/lng` 有限的点；无点返回 null；
- 调 `requestStaticMap({ points, width: POSTER_MAP_W, height: POSTER_MAP_H, zoom: pickZoom(points) })`；
- `ArrayBuffer` → `data:image/png;base64,...`；
- 模块级 `Map<string,{expiresAt, value}>` 缓存，key = `${cacheKey}:${dayIndex}:${coordsHash}`，TTL 6h；命中直接返回；
- 单天失败 `catch` → null + `console.warn`，不抛出；
- **不得**被客户端组件 import（可加注释说明）。

### ② `lib/route-poster.ts`
- 导出 `POSTER_MAP_W`/`POSTER_MAP_H`（即现 `MAP_W`/`MAP_H`）与 `pickZoom`（供服务端复用，避免复制口径）；
- `renderRoutePoster` 增加可选 `mapImages?: (string|null)[]`：
  - 第 i 天有 `mapImages[i]` → 用 `loadImage(dataUrl)` 得到图片（HTMLImageElement 可被 drawImage）；
  - 否则沿用现有 `fetchDayMapBitmap`（会员导出长图路径不变）；
- 绘制逻辑、尺寸、二维码、条形码、占位框全不变。

### ③ `components/share/SharePosterCard.tsx`
- props 增加 `mapImages?: (string|null)[]`；传给 `renderRoutePoster`；
- 其它不变。

### ④ `app/share/[token]/page.tsx`
- 仅在 `viewerTier === 'free'` 分支、渲染 `SharePosterCard` 前：
  `const mapImages = await buildSharePosterMapImages(snapshot, token);`（token 已在该页可用；用分享 token 作 cacheKey）
- 把 `mapImages` 传给组件；
- 会员/失效分支不调用。

## 4. 风险

- 首次匿名打开多天路线会消耗 N 次静态图额度（每天 1 次）；已用 6h 进程缓存兜底。
- 缓存仅单进程（多实例各自一份）；当前单机部署可接受。
