# T-073 工具条按钮互换 + 二维码分享弹窗改机票/票根风格

> 来源：用户 2026-11-08 21:12 反馈：
> 1. 工具条「导出长图」（绿框）与「保存路线」（红框）**互换位置**；
> 2. 点击「导出长图」后弹出的二维码/链接弹窗，**外形与风格改成机票（登机牌）样式**；内容仍只保留原来的二维码、链接、下载/复制/关闭，不要塞入长图里那堆城市/天数信息。

## 1. 按钮互换

`components/route/RouteResultClient.tsx` 工具条当前顺序：调整 → 截图模式 → **导出长图（RouteShareButton）** → **保存路线**。
改为：调整 → 截图模式 → **保存路线** → **导出长图**。
- 桌面 `md:flex` 与手机 `grid-cols-2` 都按新顺序；
- 按钮样式/文案/onClick 不变。

## 2. 弹窗改票根风格

`components/route/RouteShareButton.tsx` 的弹层（当前白色普通卡片）改为登机牌票根外观：
- 米白票面 `#fffdf8`、圆角 2xl、大阴影；
- 顶部渐变条 teal→amber→rose；
- 票头：左侧自绘路线小 logo + 产品名「旅行美食一条线」，右侧徽章 `ROUTE PASS / 路线分享`；
- 标题沿用 `MESSAGES.SHARE.modalTitle`（路线长图 / 二维码分享），下面一行 `modalDesc`；
- 主体保持原内容：
  - 二维码（`qr` 图，180×180）+ 扫码提示；
  - 「分享链接」标签 + 链接（truncate）；
  - 「下载长图」「复制分享链接」两个按钮；
  - 「关闭」按钮；
- 底部可加撕票虚线（+ 左右半圆缺口，颜色与遮罩协调即可），**不加**城市/天数/地点列表等长图信息；
- loading / error 状态也放在同一票根外壳内（渐变条 + 票头保留）；
- 弹窗 max-w-sm，390 宽度不溢出、QR 完整。
