# T-036 图标语义化：宝塔/宫殿/博物馆/公园/街巷 + 美食细分，覆盖首页 SVG

> 用户 2026-10-24：① 图标重复（景点全是山峰、美食全是碗），要按语义区分（宝塔、宫殿等），可参考 UI 图标库；② **首页右侧那块示意图没换**。

## 1. 目标

1. 建立**地名 → 图标**的语义映射，景点与美食都不再"一个图标打天下"
2. 三处全部覆盖：**首页右侧 SVG 示意**、**登录页左侧海报**、**导出长图（Canvas）**
3. 图标风格统一（线性/实心一致）、语义可辨（塔就是塔、宫殿就是宫殿、饺子就是饺子）

## 2. 图标集（建议）

| key | 语义 | 关键词匹配 | 来源 |
|---|---|---|---|
| `pagoda` | 宝塔 | 塔 / 寺 / 庙 / 禅 / 鼓楼 | **自绘 SVG**（参考 MDI `pagoda`，Apache-2.0，注释注明） |
| `palace` | 宫殿 | 宫 / 殿 / 城 / 府 / 苑 | 自绘（参考 MDI `temple`/`castle`） |
| `museum` | 博物馆 | 博物馆 / 展馆 / 纪念馆 / 美术馆 | lucide `Landmark` |
| `park` | 公园 | 公园 / 花园 / 植物园 / 湖 | lucide `Trees` |
| `street` | 街巷 | 街 / 巷 / 里 / 市 / 广场 / 步行街 | lucide `Store` |
| `bowl` | 面/饭/汤 | 面 / 粉 / 饭 / 汤 / 锅（非火锅） | lucide `Soup` |
| `dumpling` | 饺子/包子 | 饺 / 包 / 馄饨 / 抄手 | 自绘（半圆+褶） |
| `skewer` | 烧烤/串 | 串 / 烧烤 / 烤 / 肉 | 自绘（签子+肉块） |

| 默认 | 其它 | —— | 景点 `museum`，美食 `bowl` |

**优先顺序**：先按关键词，其次按 `type`（attraction/food），最后默认。

## 3. 三处改造点

| 位置 | 现状 | 改后 |

## 4. 数据

`config/messages.ts` 的 `SAMPLE_ROUTE.stations` 为 5 个成都站点：宽窄巷子、陈麻婆豆腐、人民公园、钟水饺、春熙路。
建议新增 `stationIconKeys: PlaceIconKey[]`（不要写死在组件里）：
`['street','bowl','park','dumpling','street']`，或直接由 `iconKeyFor(name, type)` 推导。

## 5. 实现方式

- 新建 `Project/lib/place-icon.ts`：`iconKeyFor(name: string, type: 'attraction'|'food'): PlaceIconKey`（纯函数，可单测）
- 新建 `Project/components/icons/PlaceGlyph.tsx`：按 key 返回 SVG（24×24 viewBox，`currentColor`）
- Canvas：`lib/route-poster.ts` 内用同一套路径数据绘制（**不得用 emoji**）
- 单测：`iconKeyFor` 至少覆盖 6 组关键词 + 默认分支

## 6. 明确禁止

- 不得引入运行时图标库依赖（lucide 已在用可复用；自绘图标写 SVG path）
- 不得用 emoji
- 不得改海报布局/配色体系/文案
- 不得让同一天内所有景点显示同一图标（除非语义确实相同）
