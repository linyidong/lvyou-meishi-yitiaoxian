# T-081 会员导出长图：地图按路线页编号/配色/线色/地名绘制

> 来源：2026-11-08 走查 07。会员导出长图的地图仍是「统一红点 + 紫线」，与路线页/分享海报（编号、景点青绿/美食橙、按天线色、地名）不一致。

## 1. 改动

1. `lib/route-poster.ts`
   - 新增 `pickFitZoom`（与分享海报共用口径，10–16，42% 边距）；
   - `fetchDayMapBitmap` 支持 `markers` / `labels` / `lineColor` / `zoom`，走 `/api/amap/staticmap` 查询参数；
   - 每天构造 marker（1..9、景点 `#14b8a6`、美食 `#f59e0b`）与地名标签（上/下交替 26px），线色按 `DAY_COLORS`。
2. `app/api/amap/staticmap/route.ts`
   - 解析可选 `markers=lng,lat,label,color;...`、`labels=lng,lat,text;...`、`lineColor=#RRGGBB`；
   - 透传 `requestStaticMap`；不传时保持旧行为。
3. 分享海报 helper 改用 route-poster 的 `pickFitZoom`，删除重复实现；缓存 `v7`。
