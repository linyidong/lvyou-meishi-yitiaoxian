# T-035 海报序号改为「景点/美食图标 + 序号」

> 用户 2026-10-24：把海报里纯数字的 1/2/3/4 换成景点与美食图标（或图标+序号），让人一眼看出"景点美食一条线"的产品逻辑。

## 1. 目标

两处海报的序号圆点，从**纯数字**改为 **类型图标 + 小序号**：

| 位置 | 现状 | 改后 |
|---|---|---|
| 登录页左侧渐变海报示意条（`LoginClient.tsx:228-248`） | `h-8 w-8 rounded-full` 内显示 1–4 | 圆内显示图标（景点/美食），序号以小字或角标呈现 |
| 导出长图（`lib/route-poster.ts:175-182` 列表序号 + 路径示意图圆圈） | 数字 1..n | 同：图标 + 序号 |

视觉规范：
- **景点**：山峰（或相机）图形；**美食**：碗筷（或碗+热气）图形
- 颜色沿用现有语义：景点=青绿（teal/emerald）、美食=橙色（amber/orange）
- 图标与序号都要能辨认：建议**图标居中、序号做右下角小徽标**（或在圆下方写序号），保证与下方/旁边清单的编号能对应
- 图标一律用**矢量绘制**（Canvas 用路径，HTML 用 SVG 或 lucide 组件），不得使用 emoji（导出图在不同设备字体不一致）

## 2. 不做什么

- 不改海报布局、文案、配色体系
- 不改二维码、图例、里程信息
- 不改其它页面
- 不引第三方图标库（HTML 侧用已有 lucide-react；Canvas 侧用自绘路径）

## 3. 现状证据（Harness 实测）

| 项 | 位置 |
|---|---|
| 登录海报示意条 | `components/auth/LoginClient.tsx:228` 起，`SAMPLE_ROUTE.stations.slice(0,4)`，圆点为 `h-8 w-8 rounded-full` + `i+1` |
| 示例路线数据 | `config/messages.ts` 的 `SAMPLE_ROUTE`（`stations` 5 个，无类型字段） |
| Canvas 列表序号 | `lib/route-poster.ts:175-182`（26×26 圆角方块 + 数字） |
| Canvas 路径图圆圈 | 同文件路径绘制段（`strokeStyle = '#E7E5E4'` 附近，按 `place.type` 着色） |

**注意**：`SAMPLE_ROUTE.stations` 没有类型信息。需按顺序定义类型（示意路线为：1 宽窄巷子=景点、2 陈麻婆豆腐=美食、3 人民公园=景点、4 钟水饺=美食、5 春熙路=景点），建议在 `SAMPLE_ROUTE` 增加 `stationTypes: PlaceType[]`，不要写死在组件里。

## 5. 明确禁止

- 不得使用 emoji 或外部图片
- 不得改变站点数量、顺序、文案
- 不得降低可读性（图标+序号在 26px 尺寸下仍需可辨，必要时把列表圆点放大到 30px）
- 不得改动导出图片的整体尺寸与布局

- [ ] 景点/美食配色与现有图例一致（青绿/橙色）
- [ ] 导出图在 26px 圆点下图标仍可辨认（放大到 30px 亦可）
- [ ] `npm run typecheck` exit 0、`test:run` 全过、`test:e2e` 8 条通过
