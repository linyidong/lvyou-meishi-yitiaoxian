# T-088 登录 / 注册支持「邮箱或手机号」

> 用户 2026-11-09 01:15：登录页与注册页的账号类型改为「邮箱或手机号」。

## 1. 改动

- 新增 `lib/phone.ts`：`normalizeChinaPhone`（11 位 / +86 → E.164 `+86...`）、`isEmailLike`。
- UI `LoginClient`：
  - 账号标签「邮箱或手机号」，占位「例如 xiaoman@qq.com 或 13800138000」；
  - 校验接受邮箱或手机号；注册用户名未填时手机号默认展示为手机号；
  - 重置密码仍限邮箱（`注册邮箱`），避免无短信通道时误导。
- API `POST /api/auth/login`：
  - 手机号 → `signInWithPassword({ phone, password })`；
  - 邮箱 → 原逻辑不变。
- API `POST /api/auth/register`：
  - 手机号 → `admin.createUser({ phone, password, phone_confirm: true })`（自建版无 SMS，管理员直接确认）；
  - 邮箱 → 原 `email_confirm: true` 逻辑；
  - 支持可选 `username`，手机号未填用户名时用手机号展示；
  - `public.users.email` 手机号账号为 null，展示名走 `users.username` 或 `auth.users.phone`。
- `app/(user)/layout.tsx`：displayName 兜底 `user.phone`。

## 3. 说明

- 已有邮箱账号（如 `18960133530@qq.com`）仍用邮箱登录；手机号登录只适用于手机号注册的新账号。
- 自建 Supabase 未配置 SMS，手机号注册通过 service_role `phone_confirm:true` 跳过验证码；上线如接短信可改回 OTP。
