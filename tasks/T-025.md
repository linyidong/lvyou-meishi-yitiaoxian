# T-025 内测模式：关闭对外付费入口（BILLING_ENABLED）

> 依据：`docs/decisions.md` D-14（用户 2026-10-22：个人主体备案 + 内测不收费）。
> 这是**合规要求**，不是体验优化：内测期间不能让用户完成支付。

## 1. 目标

用一个配置开关控制收费能力：`BILLING_ENABLED = false` 时，用户侧看不到也走不通任何付费路径；后台核销历史订单不受影响。

## 2. 不做什么

- 不删除会员体系与收银台代码（只是关闭入口）
- 不改配额、不改会员判定
- 不改后台手工核销逻辑
- 不删历史订单数据

## 3. 现状

- 收费入口：`Project/components/profile/MemberCard.tsx`（收银台、下单按钮）
- 升级引导：`Project/components/member/MemberUpsellCard.tsx`（T-008 新增）、`/profile` 的升级按钮
- 下单接口：`Project/app/api/member/orders/route.ts`

## 4. 涉及模块与允许修改的文件

| 文件 | 允许的改动 |
|---|---|
| `Project/config/business.ts` | 新增 `BILLING_ENABLED`（默认 `false`，附注释说明开启条件） |
| `Project/components/profile/MemberCard.tsx` | 关闭时隐藏购买区，展示「内测阶段暂未开放购买」 |
| `Project/components/member/MemberUpsellCard.tsx` | 关闭时不渲染（或改为"内测中"提示） |
| `Project/app/api/member/orders/route.ts` | **服务端兜底**：关闭时 POST 返回 403 + 明确文案 |
| `Project/config/messages.ts` | 内测文案 |
| `Project/tests/` | 补 1 条：关闭时下单接口 403 / 组件不渲染入口 |
| `docs/progress.md`、`docs/known-issues.md`、`docs/handover/阶段7-编码-交接摘要.md` | 同步 |

## 5. 明确禁止

- 不得只在前端隐藏而服务端仍可下单（必须双保险）
- 不得删除收银台/会员代码
- 不得影响后台核销与已有会员身份

## 6. 实施步骤

1. `config/business.ts` 增加 `BILLING_ENABLED = false`（注释写清开启条件）
2. 前端：`MemberCard` 购买区按开关渲染；`MemberUpsellCard` 关闭时返回 `null`
3. 服务端：`POST /api/member/orders` 首行判断，关闭即 403 + `MESSAGES.MEMBER_ORDER.paused`
4. 文案：`MESSAGES.MEMBER_ORDER.paused = '内测阶段暂未开放购买，感谢关注'`
5. 测试：单测断言「关闭时下单接口 403」（可 mock 或直连 dev server）；若走 E2E 需登录，可写为单测导出判断函数

## 7. 验收标准

- [ ] `BILLING_ENABLED=false` 时：`/profile` 不出现购买按钮，显示内测提示
- [ ] 游客结果页不渲染 `MemberUpsellCard`
- [ ] 直接 POST `/api/member/orders` 返回 **403** 且文案明确
- [ ] 后台订单核销仍可用（人工验证）
- [ ] 把开关改成 `true` 后行为恢复（临时验证后改回 `false`）
- [ ] `npm run typecheck` exit 0、`npm run test:run` 通过
- [ ] 不跑 build

## 8. 自动化测试

| 命令 | 预期 |
|---|---|
| `npm run test:run` | 原有 30 + 新增用例通过 |
| `curl -X POST /api/member/orders`（未登录） | 401（鉴权优先） |
| 登录后 POST（内测关闭） | **403 内测文案** |

## 9. 人工验收

管理员登录 → 个人中心：看不到「立即开通」；游客结果页：看不到升级卡；后台仍能核销订单。

## 10. 失败恢复

把 `BILLING_ENABLED` 改回 `true` 即恢复；或 `git revert`。

## 11. 风险等级

**低**（一个开关 + 服务端兜底）。
