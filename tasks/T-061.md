# T-061 长图导出改版：机票风格 + 每天一张地图路线截图

> 用户 2026-10-25：「导出长图里应加上地图路线截图（绿色框位置）；整体设计应像机票风格，带上我们的 logo 图标和名称」。

## 1. 现状

`lib/route-poster.ts` 纯 canvas 自绘：标题 + 每天地点列表 + 二维码；**没有地图**，样式朴素。
`RouteResultClient` 点击「导出长图」生成并下载。

## 2. 目标

### ① 地图路线截图（每天一张）
- 新增服务端代理 `GET /api/amap/staticmap`：
  - 入参：`coords`（`lng,lat;lng,lat;...` 当天有序点）、`size`（如 `640*360`）、`zoom`（10–16）
  - 服务端调用高德 `v3/staticmap`（走 Key 池 + 记 `amap_usage(service='staticmap')`），返回 `image/png`
  - 校验：登录用户、坐标数量 ≤30、size ≤ `1024*1024`、zoom 范围；失败返回 400/502
- 长图绘制前先并发拉取每天地图（`fetch` → `createImageBitmap`），失败时画占位框（灰底 + 「地图暂不可用」）不阻断导出

### ② 机票（登机牌）风格
- 整体：顶部主色渐变票头 + 白色票身 + 底部虚线撕票线（圆孔）+ 条形码
- 票头：**logo 图标**（圆角方块 + 路线拐点符号，canvas 自绘）+ 「旅行美食一条线」+ 小字「ROUTE PASS / 路线机票」
- 票身信息区（两列/三列）：`城市 / 天数 / 地点数 / 出行方式 / 导出日期`
- 每天区块：
  - 「第 N 天 · X 个地点」标签（pill）
  - **地图截图**（圆角、描边）
  - 站点清单：序号 + 名称 + 类型 chip（景点/美食）
- 底部：二维码 + 「扫码打开网页版查看完整路线」+ 域名 + 条形码条带
- 尺寸：宽 1080，高度自适应；颜色用 `primary-from→primary-to` 渐变 + stone 底 + teal/amber 点缀

## 3. 不做什么

- 不改路线页其它 UI
- 不引入绘图库（纯 canvas）
- 不改二维码内容（仍指向分享页）

## 4. 验收标准

- [ ] 长图中**每天都有地图截图**，且路线与当天点位一致
- [ ] 机票风格：logo + 名称 + 票头渐变 + 撕票虚线/圆孔 + 条形码
- [ ] 1080 宽、清晰可读；地点多（16 个）时不重叠、不截断
- [ ] 地图接口失败时导出仍成功（占位框 + 提示）
- [ ] `/api/amap/staticmap` 未登录 401；坐标/参数非法 400
- [ ] `typecheck` 0、`test:run` 全过、`test:e2e` 8 条通过
- [ ] 改完重启 dev 再截图（A8）

## 5. 测试方案（Harness）
