\# 旅行美食一条线 · 同步清单参数 v1.0

\## 0. 使用说明

\- 本清单同步自 [`人工必填清单-v1.0.md`](http://人工必填清单-v1.0.md)。

\- 每个参数对应一个代码常量。

\- 代码必须引用本清单，不允许硬编码。

\- 密钥类参数只从环境变量读取，不写入代码。

\- 修改本清单后，同步修改 `config/` 下对应文件。

\## 9. 使用规则

\### 9.1 代码引用示例

\`\`\`ts

import { PRODUCT } from '@/config/product';

import { ROUTES } from '@/config/routes';

import { BUSINESS } from '@/config/business';

import { PLACE\_TYPE, TRANSPORT } from '@/config/enums';

import { MESSAGES } from '@/config/messages';

&lt;h1&gt;{[PRODUCT.NAME](http://PRODUCT.NAME)}&lt;/h1&gt;

&lt;Link href={[ROUTES.CITY](http://ROUTES.CITY)}&gt;选择城市&lt;/Link&gt;

if (places.length &gt; BUSINESS.MAX\_PLACES\_PER\_DAY) { ... }

if (type === PLACE\_[TYPE.FOOD](http://TYPE.FOOD)) { ... }

toast(MESSAGES.LOGIN\_REQUIRED);

\`\`\`

\### 9.2 禁止事项

\- 禁止在组件里写死 `'旅行美食一条线'`。

\- 禁止在组件里写死 `/city`。

\- 禁止在组件里写死 `10`、`5`、`60` 等业务数值。

\- 禁止在组件里写死 `'景点'`、`'美食'`、`'步行'`、`'骑行'`。

\- 禁止把密钥写入 `config/`，只能从 `config/env.ts` 读环境变量。

\### 9.3 修改流程

1\. 先改 [`人工必填清单-v1.0.md`](http://人工必填清单-v1.0.md)。

2\. 再改本清单对应常量。

3\. 再改 `config/` 下对应文件。

4\. 代码自动生效，无需改组件。
