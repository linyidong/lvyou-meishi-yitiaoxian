## 4. 今晚的错误与解决

| # | 现象 | 根因 | 解决 |
|---|---|---|---|
| 1 | 功能建议「选好了还报请选择」 | 校验把「未选 / 空 / <5 字」合并成一条文案 | 拆分三种提示 + 输入框下加「至少 5 个字」 |
| 2 | 单条清理报 400，批量正常 | API 批量分支条件写成 `hidden===true \|\| ids 是数组`，单条请求被误判 | 只按 `ids` 是否为数组分流 |
| 3 | 全站 503（约 6–8 分钟） | 手动 stop→build→start 被中断，服务停住、`.next` 半成品 | 重新构建恢复；新增 `deploy/remote-deploy.sh`（备份 `.next`、失败/中断自动回滚） |
| 4 | 高德弹「起点与终点不能为同一地点」 | 住宿闭环把导航拼成「住宿→地点→回住宿」，首尾相同 | 去重、去掉末尾回程点、同坐标不请求高德 |
| 5 | iPhone Safari 标题折成「成都·吃 / 喝一条线」 | 结果页图例 `shrink-0` 挤占标题宽度 | 手机端标题与图例上下排 |
| 6 | 顶部品牌名在 Safari 折行 | 品牌名可换行、Safari 字体略宽 | `whitespace-nowrap + truncate` |
| 7 | 周边地名看不清 / 互相压盖 | 8px 浅灰点 + 10px 浅灰字 | 深灰点 + 白底胶囊 + 四方向 + 去分店名 |

| 9 | GitHub 推送多次超时 | 网络到 github.com:443 不稳定 | 记录未推状态，改天重试；代码/线上不受影响 |
