## 7. 项目整体业务逻辑

### 7.1 产品与用户
- 产品：旅行美食一条线（`https://lyytx.com`）
- 用户角色：**游客**（免登录试用）、**注册用户**（免费档）、**会员**（付费）、**管理员**
- 核心价值：把小红书/抖音收藏的景点与美食，按顺路顺序自动排成可执行的一日/多日路线

### 7.2 主流程（6 步）
选城市 → 设置路线（出发城市/城际/住宿/天数/市内交通）→ 导入地点（文案提取/搜索/收藏）→ 勾选地点 → 调整路线（上下移动/按天）→ 查看结果（地图、分段里程、保存/分享）

### 7.3 游客口径（铁律）
- 游客**能**走完新建路线的完整流程（选城市 → 设置 → 导入/勾选 → 调序 → 地图/里程）；
- **唯一差别**：保存路线需登录；顶部工具栏（含 logo）全部置灰；
- 免登录限流按成本分桶：`import`/`order` 3 次/日、`city-places` 100 次/日、`reorder` 60 次/日。

### 7.4 会员与配额
- 月卡 ¥9.9（D-16）；`BILLING_ENABLED=true`（个人备案下收费属合规灰区，知情承担）；
- 免费：每天 1 条单日路线、单日地点上限、AI 识别 1 次/日；
- 会员：每月 5 条、最长多日、单日更多地点、AI 次数更多、长图导出与分享导入；
- 管理员：不限次数/天数/地点数。

### 7.5 分享分级
- 免费/游客看「海报视图」（服务端裁剪，不含坐标/地址）；
- 会员可导入分享路线（`/share/[token]` → 预览 → 建成自己的路线）。

### 7.6 数据模型（核心表）
`users`、`cities`、`places`、`routes`、`route_places`、`route_shares`、`member_orders`、`member_logs`、`user_daily_usage`、`events`、`imports`、`app_settings`、`amap_usage`、`amap_leg_cache`、`amap_geocode_cache`、`feedback`(新)。

### 7.7 技术架构（当前生产）
```
用户 ──443──▶ 云机 Nginx（TLS/HSTS/HTTP2）
                ├── /            → 127.0.0.1:3000（Next 14.2.35，lvyou.service）
                └── /rest /auth  → 127.0.0.1:8000（Kong → PostgREST / GoTrue）
                                      └── 127.0.0.1:5432（supabase/postgres 15.8）
```
- 外部服务：高德（JS API + Web 服务 Key 池）、DeepSeek（文案提取）、企业微信（订单通知 + 监控告警）、腾讯 OCR（可选）。

### 7.8 管理员后台
概览 / 用户列表 / 在线用户 / 地点列表 / 路线列表 / 导入记录 / 会员订单（核销）/ 设置（三开关）/ 技术栈 / **意见箱**。
