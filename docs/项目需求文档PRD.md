## 1. 项目概述

「旅行美食一条线」是一个**自动排路线的旅行规划工具**：选城市 → 设行程（出发城市/天数/市内交通/住宿）→ 挑地点（库内 1326 条 + 自行导入）→ 自动排序生成路线 → 看地图与分段里程时间 → 保存为个人路线 / 分享。

商业化：游客可免登录完整试用，保存时需登录；会员按档位享受更高配额与权益；管理员后台负责订单核销、用户与地点管理。

`[已确认]` 依据：`docs/project-brief.md`、`docs/feature-status.md`、`docs/module-map.md`。

## 2. 问题与目标

- **核心业务目标**：付费转化优先 `[已确认]`
- **用户问题**：做旅行路线时要手工拼景点、算远近、估时间，且小红书/抖音收藏的地点散落各处
- **成功指标**：真实用户完整跑通 1 轮「游客试用 → 注册 → 付费 → 开通成功」，全程无报错 `[已确认]`
- **非目标**：本期不做生产部署、CI/CD、年卡/永久卡、付款自动回调、企微自建应用个人微信通知 `[已确认]`
- **衡量口径**：以端到端链路能否跑通为准，不以"代码看起来对"为准

## 3. 用户与场景

| 角色 | 能力边界 | 证据 |
|---|---|---|

## 5. 关键用户流程

1. **游客试用**：`/city` 选城市 → `/try/new` 设行程（出发城市必填）→ `/try/pick` 挑地点（可导入）→ `/try/result` 看路线（可拖拽调序、可一键复位）→ 点「保存路线」→ 提示登录 → `/login?redirect=/try/result` → 登录后草稿转正落库
2. **直接注册**：`/login` 注册 → 首页 → `/route/new` 全流程 → 保存
3. **付费**：`/profile` 看权益与配额 → 收银台下单 → 展示收款码 → 管理员后台核销 → 会员生效（轮询/刷新可见）
4. **分享**：会员分享路线 → 生成链接/二维码 → 接收方打开：
   - 会员：看完整路线 → 可导入保存（受配额约束）
   - 非会员/游客：**只看路线图片** + 「升级会员可导入」→ 引导注册/升级

## 7. 业务规则与边界条件

1. **免登录限流按成本分桶**（不可改回统一 3 次/日）：`import`/`order` 3 次/日、`city-places` 100 次/日、`reorder` 60 次/日 `[已确认]`
2. **游客能力口径**：全流程可用，仅保存需登录；工具栏全置灰 `[已确认]`
3. **分享导入**：仅会员（`tier !== 'free'`）可导入，且受路线配额约束 `[已确认]`
4. **会员到期**：配额与 UI 读取侧已按 `member_until` 惰性回落；本期追加定时写回 + 后台可见 `[已确认]`
5. **一键复位**：只还原本地快照，不触发任何接口调用 `[已确认]`
6. **重复提交/并发**：订单与保存路线的幂等性 `[待确认]`（阶段 6 核对）
