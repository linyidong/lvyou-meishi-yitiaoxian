# 操作手册（旅客视角）

> 面向：使用者（你和试用朋友）。技术细节见 `技术栈文档.md`，设计取舍见 `项目思维逻辑.md`。
> 最后更新：2026-10-25

## 1. 这是什么

「旅行美食一条线」把小红书/抖音里的**景点与美食**整理成一条**按路顺路排好**的路线，并给出地图与分段里程，可保存、可分享、可导出长图。

核心一句话：**你把想去的地方丢进来，它替你排顺序、算距离、出图。**

## 2. 三种使用形态

| 形态 | 入口 | 能做什么 |
|---|---|---|
| 游客 | 首页「开始排路线」 | 完整体验：选城市 → 设行程 → 导入/勾选地点 → 调顺序 → 看地图与里程；**保存路线需登录** |
| 正常用户（注册） | 登录后首页 | 保存路线（单日 1 条/天）、收藏地点、AI 提取次数 10 次/天 |
| 会员 | 管理员开通或付费 | 每月 5 条路线、AI 提取 20 次/天、导入分享路线、导出长图 |

## 3. 电脑上怎么用

1. 打开 `http://localhost:3000`（本机）或 `http://<本机IP>:3000`（同一 WiFi 的手机）
2. 首次进来用**游客模式**：点「开始排路线」→ 选城市（如「东山（东山岛）」）→ 设天数与出行方式
3. 两种加地点方式：
   - **AI 提取**：把小红书笔记文案粘进「粘贴笔记文案」，点「AI 提取地点」；或上传截图/长图用「图片识别」
   - **手动**：在「我的收藏地点」里勾选，或搜索添加
4. 结果页：拖动/箭头调顺序，右侧地图实时更新，顶部显示当天里程与时长
5. 保存（需登录）→ 「我的路线」里可再次编辑、分享、导出长图

## 4. 手机上怎么用

同一个 WiFi 下，手机浏览器输入**运行应用那台电脑**的局域网地址（启动脚本会直接打印出来），例如：

```
http://<当前运行应用的电脑 IP>:3000
```

> Windows 第一次被手机访问前，需要**以管理员身份运行** `windows\允许局域网访问.bat`（放行 3000 端口）。

## 5. 启动与关闭

### Mac
- 启动：双击项目根目录 `启动项目.app`（或 `启动项目.command`）
- 停止：双击 `停止项目.command`

### Windows（Supabase 所在的那台）
1. 首次准备：
   - 安装 Node.js 18+、Docker Desktop（Supabase 容器）
   - 把 Mac 上的 `Project\.env.local` 复制到 `Project\.env.local`（**这个文件含密钥，不要发群里**）
   - 如 Supabase 的 `docker-compose.yml` 不在默认位置，在 `windows\config.bat` 里设置 `SUPABASE_DIR`
   - 右键管理员运行一次 `windows\允许局域网访问.bat`
   - 运行 `windows\创建桌面快捷方式.ps1`（桌面上会出现启动/停止/诊断三个图标）
2. 日常：双击桌面「旅行美食一条线-启动」→ 黑窗里显示 5 步进度（Node/配置/Supabase/依赖构建/启动）→ 完成后**自动打开电脑浏览器**，并醒目打印**手机测试地址**（自动识别可用局域网 IP、已复制到剪贴板）
3. 关闭：双击「旅行美食一条线-停止」
4. 出问题：双击「旅行美食一条线-诊断」，它会打印 Node/npm/配置/依赖/Supabase/端口/局域网 IP/防火墙 的体检结果

> **只开 Windows 也能测试**：应用与数据库都在这台机器上，Mac 可以关机。

## 6. 账号与会员

| 角色 | 说明 |
|---|---|
| 游客 | 免登录试用，不能保存 |
| 正常用户 | 注册即可，单日路线 1 条/天、收藏不限 |
| 会员 | 后台「会员订单」里核销，或「用户列表」里手动开通 |
| 管理员 | 后台 `/admin`，只读 + 设置/技术栈 |

## 7. 常见操作路径（速查）

| 想做什么 | 路径 |
|---|---|
| 排一条新路线 | 首页 → 开始排路线 |
| 导入别人的分享 | 首页 → 导入分享路线 → 粘贴链接 / 上传含二维码长图 → 预览 → 建成路线或只收藏 |
| 收藏地点 | 结果页点收藏，或导入时选「只收藏地点」 |
| 导出长图 | 路线结果页 → 导出长图（机票风格，每天一张地图） |
| 看会员权益 | 个人中心 → 会员卡 |
| 改配额/开关/模型 | 后台 → 设置（AI 模型 / 业务开关 / 配额数字，分块保存） |
| 看技术栈 | 后台 → 技术栈（一页铺开） |
| 看导入记录/用量 | 后台 → 导入记录 / 概览（含高德与 OCR 用量） |

## 8. 测试清单（每次改动后建议走一遍）

1. 游客：选城市 → 加 3 个地点 → 调顺序 → 地图有折线与里程
2. 登录：保存路线 → 「我的路线」能看到
3. AI 提取：粘一段小红书文案 → 提取出地点 → 收藏
4. 图片识别：截一张笔记图 → 上传 → 文本回填 → 提取
5. 分享：分享路线 → 复制链接 → 另开无痕窗口导入 → 预览 → 只收藏
6. 长图：导出 → 检查每天有地图、二维码可扫
7. 后台：概览数字正常、设置能保存、技术栈页可交互

## 9. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面打不开 / 一直转圈 | 应用没启动（不是数据库挂了） | 双击启动脚本；或 `cd Project && npm run check:env` 看哪一层不通 |
| 登录失败、数据空白 | Supabase 容器没起来 | Windows 上打开 Docker Desktop，等容器 Running；诊断脚本看 8000 端口 |
| 手机打不开 | 防火墙 / 不同 WiFi | 管理员运行 `允许局域网访问.bat`；确认手机与电脑同一 WiFi；用诊断脚本里的 IP |
| 提示「路线次数已用完」 | 当日额度用尽 | 升级会员，或后台「设置 → 配额」调整（管理员） |
| 提示「图片识别已暂停 / 导入已暂停」 | 后台开关被关 | 后台 → 设置 → 业务开关，打开后刷新页面 |
| 提示高德额度不足 | 高德 Key 当日配额用尽 | 应用会切 Key 2；等次日恢复，或减少批量导入 |
| 地点地址跑到别的城市 | 历史数据 | 已修（城市限定 + adcode 精确匹配）；旧数据可重跑 `npm run scan:water -- --all` 体检 |
| 长图二维码扫不出 | 旧版长图（二维码被裁切） | 重新导出（新版已修） |

## 10. 备份与恢复

- 数据库备份：`deploy/backup-db.sh`（每日 pg_dump）
- 代码备份：本地 Git + 盘外备份目录 `_backups/` + GitHub
- 恢复顺序：先起 Supabase → 导入备份 → 起应用 → 首页自检
