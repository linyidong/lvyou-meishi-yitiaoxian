# 技术栈文档

> 最后更新：2026-10-25 · 与后台「技术栈」页同源（`config/messages.ts` 的 `ADMIN_TECH_STACK`）

## 1. 全景

```
浏览器 / 手机浏览器
   │  HTTPS(待备案) / HTTP(局域网)
   ▼
Next.js 14 App Router（页面 + Route Handlers 同仓）
   │  @supabase/ssr（Cookie 会话）
   ▼
自建 Supabase：PostgREST ── GoTrue(Auth) ── PostgreSQL 15
   │
   └─ 外部服务：高德（JS API + Web 服务 Key 池）、DeepSeek（文案提取）、腾讯云 OCR（图片识别）、企业微信（订单提醒）
```

## 2. 前端

| 技术 | 版本 | 用途 | 关键位置 |
|---|---|---|---|
| Next.js | 14.2.15（App Router） | 页面、SSR、Route Handlers | `app/` |
| React | 18.3.1 | 交互组件 | `components/`（48 个） |
| TypeScript | strict | 全仓类型 | `tsconfig.json` |
| TailwindCSS | 3.x | 样式、主色渐变 `primary-from→primary-to` | `tailwind.config.ts` |

## 4. 数据层（自建 Supabase）

| 组件 | 用途 |
|---|---|
| PostgreSQL 15 | 业务数据（15 张表） |
| PostgREST | 自动 REST API |
| GoTrue | 注册/登录/管理员用户 API |
| RLS | 行级安全（用户只能读写自己的数据） |
| pg_cron | 每日 03:05 会员到期翻转（迁移 026） |
| 原子 RPC | `replace_route_places` / `approve_member_order` / `create_member_order_guarded` / `create_route_guarded` |

### 核心表

```
users(id, email, admin, member, member_until, member_source, trial_multi_day_used)
places(id, user_id, city_id, name, type, lat, lng, address, is_collected, geo_status)
cities(id, name, adcode)            ← 109 个城市
routes(id, user_id, city_id, title, days, transport, imported_from, ...)
route_places(route_id, place_id, day_index, order_index, slot)
route_shares(token, route_id, snapshot, revoked_at)
member_orders(id, user_id, plan, amount, pay_channel, status, ...)
member_logs / user_daily_usage / amap_usage / amap_leg_cache / amap_geocode_cache
imports / events / app_settings(key jsonb)
```

- 迁移 **32 份**，全部手工执行；`npm run check:schema` 按对象核对（63 项）

## 5. 地图与算路

| 能力 | 实现 |
|---|---|
| 地点检索 | 高德 `place/text` + `citylimit=true` + adcode 精确匹配（区县级必须相等） |
| 地址补全 | 命中同城才写入；adcode 缺失用逆地理补；无同城结果→`unmatched`（宁缺勿错） |
| 距离矩阵 | 高德 `distance`，结果落库缓存（`amap_leg_cache`） |
| 路线排序 | 最近邻 + 2-opt（`lib/route-order.ts`） |
| 长图地图 | `v3/staticmap` 经 `/api/amap/staticmap` 代理（服务端 Key，防跨域） |
| 配额控制 | 双 Key 池（`AMAP_WEB_SERVICE_KEY` / `_2`）+ 每日用量表 + 熔断提示 |

## 9. 版本与依赖纪律

- 生产依赖只用 Next/React/Tailwind/lucide/@supabase/qrcode/jsqr 等必要项
- 不引入图表库、动画库；动效用 CSS + SVG
- 升级依赖前先跑 `typecheck` + `test:run` + `test:e2e`
